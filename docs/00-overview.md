# 00 · 赛事与最终成绩

## 比赛

| | |
|---|---|
| 名称 | **Kaggriculture**（Kaggle Featured） |
| 奖池 | \$50,000 |
| 参赛队 | **10,148** |
| 时间 | 2026-07-30 开幕 → **09-30 23:59 UTC 提交关闭** → **10-14 23:59 UTC 榜单定案** |
| 形式 | 双人 720 步农场模拟；共享市场；得分 = 最终资金 |

两名智能体各经营 10×10 棋盘 30 个游戏日：种植、浇水、养牲畜、雇工，
并在一个**共享市场**上交易（订单逐格撮合，价格随共同库存变动）。

## 关键规则（决定了整场比赛的形态）

1. **每天最多 5 次提交，但只追踪最新 2 份。** 新的提交会**顶掉**旧的一份，
   而这 2 份就是最终评估用的提交。
2. **提交关闭后继续跑局两周**（到 10-14），让评分收敛。
3. **最终排名 = Bradley–Terry 重算，只看胜负**，金额差不算。
4. **新提交从基线评分起步**，需要数小时到一天才能爬到真实水平。
