# V3 线上约 2400 分的本地基准审计（2026-09-18）

本审计只读现有结果和回放，不改模型、不提交。审计对象是已提交的 `candidate_v45_q25_sellsearch_v3`，父本是 Q25。原始机器结果见 [benchmark_audit.json](./benchmark_audit.json)、[online_openings.json](./online_openings.json)、[local_openings.json](./local_openings.json)。

## 结论

线上约 2400 并不能由“v3 搜索没有生效”解释。真正的证据是：v3 的确认面板在 72 个健康配对行中完全没有改变胜负或 point；其中近期高压的 V46、Reactive7 两个谱系合计 24 行全部输，而旧 Thomas、V37、Dmitri 三个相对宽松谱系合计 36 行全部赢。面板总计因此形成 48 胜、24 负，看起来比线上更乐观，但它主要是在测试已能击败的旧/同源路线。

线上已经下载的 58 场回放为 35 胜、23 负（胜率 60.3%，描述性 Wilson 95% 区间约 47.5%–71.9%），CHEN Xiang 的平均分差 +908，中位数 +566；负局平均 −646、中位数 −532。若将当前 leaderboard 约 2400 视为同一批次的积分表现，线上 W/L 与本地确认的 48/24（66.7%）存在约 6.4 个百分点的方向差异；这属于匹配样本与对手变化的描述性差异，不能把分数线性换算成胜率。

## 2. 线上回放到底有多接近我们的基准

现有线上回放 58 场、58 个不同 seed、56 个不同对手名；这使它在 seed 数量上比确认面板丰富，但它不是随机抽样，且每个公开对手大多只出现一次。

仅比较前 48 个 callback 的实际 action（不做反事实替换）：

- 对手与 v3 自身的 farmer/hands 单位动作完全相同率平均 **97.38%**；56/58 场至少 46/48 步相同，18 场 48/48 步完全相同。
- market 列表完全相同率平均 **95.44%**，整条 action（单位+market）完全相同率平均 **92.85%**。
- 负局的单位动作相同率 **98.46%**，胜局为 **96.67%**。负局并不是明显不同路线造成的，而是近镜像的最后少量市场或动作差异。

本地在同一个 seed 9060、前 48 callback 对每个可执行对手做的控制运行显示：Q25 与 Nathan/Pipe8/V37 的单位动作分别 48/48、48/48、48/48 完全相同；V46 与 Q25 为 47/48，Reactive7、Dmitri 各为 47/48，Thomas 只有 4/48（真正异构）。这说明原确认面板覆盖了大量近镜像 V45 家族，线上负局形态却同样是近镜像但末端市场/路线细节更丰富，不能用“本地已打过同一个动作”替代“已覆盖对手策略”。

线上首个 market action 还显示了确认面板没有系统覆盖的组合：

|BUY_PRODUCT WHEAT 5；BUY_PRODUCT WHEAT 10；SELL WHEAT 60|13|10/3|多批 BUY 后大批 SELL|
|BUY_PRODUCT WHEAT 70；SELL WHEAT 70|10|9/1|大批量一进一出|

这些分组本身受到对手能力、匹配时间和 seed 混杂影响；它们不能单独证明某个首回合组合具有因果劣势。但它们确实说明本地 v3 搜索的覆盖面不对齐线上：v3 只在**父动作已经是纯 SELL 且包含重复 SELL 产品**时重排，遇到 BUY→SELL 屏障、单一 SELL 或其他市场组合直接退回父动作。线上负局中，最常见的近镜像开局是 `BUY 7 / SELL 2`、`BUY 10 / SELL 10`，正好绕开 v3 的触发条件。

## 3. 为什么本地 v3 没预测线上分数

1. **目标机制和失分机制错位。** v3 搜索的是重复 SELL 块的顺序，且不跨 BUY/HIRE 屏障；线上最接近的失分通常在 BUY→SELL 顺序、批量数量、订单索引锁步和对手对市场库存的竞争。v3 的局部重排即使被触发，确认面板的 point 也没有变化。
2. **对手家族权重失真。** 确认面板四个家族全胜、两个近期家族全败；按行平均得到 66.7% 并不能代表线上匹配分布。V46/Reactive7 不是“偶然难的一两场”，而是确认面板各 12/12 负；合并 pilot 后各为 1 胜 19 负。这个负面信号在提交前已经存在，未被总体平均充分体现。
3. **开发 seed 被重复使用。** pilot 的 4 seed、确认的 6 seed 都是开发阶段固定面板；有效独立簇只有 4/6。源码/tar 重跑不是新 seed。即使没有 outcome 变化，现金差的窄区间也只描述这批世界。
4. **局部现金差不是线上分数。** 确认现金 delta +5.33 的 95% seed-cluster 区间约 [+2.89,+7.61]，但 point delta 精确为 0；现金变化没有转化为胜负。线上分差的标准差约 2487，远大于本地现金改变量（确认 sd 约 6.44），所以把 +5 现金视为可以解释约 100–1000 分的线上变化没有依据。
5. **面板包含高度相关代码。** V46、Reactive7、Pipe8、V37/V45 共享大量 chassis/route/tape；它们的“多文件”不是同样多的独立策略。线上 56 个对手名不能自动算成 56 个独立策略；前 48 步仍高度相同。线上首步市场共有 18 种签名，显示同一 chassis 内的参数/订单组合更多样，但不足以证明完整策略异构性更大。确认面板中的 Thomas 提供了明显异构控制，但它是全胜、过于容易。
6. **线上抽样存在时间与匹配偏差。** 58 场回放不是 leaderboard 全部对局，也没有每名对手的重复 seed；线上胜率 Wilson 区间宽，且同一提交会随对手池更新而改变分布。因此 2400 分只能解释为当前线上混合对手下的表现，不能由本地 72 行精确预测。

## 4. 证据边界与后续建议

当前最可靠的判断不是“SELL 重排一定有害”，而是：**v3 没有触及造成线上失分的主要行为层，确认面板在家族权重和机制覆盖上都偏离线上。**

后续要验证方向，应先建立与线上匹配的分层面板：

- **近期开局层：** V46、Reactive7、Pipe8，以及从线上回放中提取的 `BUY 5/10 → SELL 60`、`BUY 70 → SELL 70`、`BUY 7 → SELL 2` 等完整反应式对手。反应式对手必须以真实 agent 对战，不能把录制 action 逐步替换进 Q25。
- **异构层：** 至少保留 Thomas、一个真实旧路线和一个不同市场策略；按机制家族计权，每家族先取一个代表，避免 V45 同源文件重复计权。
- **未见 seed：** 每层至少 8 个全新 seed、双座位；seed 为簇，不能把两个座位当两个独立样本。预注册候选和父本的完整 W/T/L、point、cash、action changed、telemetry。
- **指标：** 主要看 point delta/W→L 或 L→W；cash 只作诊断。对每个近期家族报告胜率、margin 分布与 action digest 改变率。
- **针对性机制：** 先复盘线上 `BUY→SELL` 的订单索引和价格库存演化，验证是否存在跨屏障全局排序收益；若没有可证明的安全 oracle，就不要继续扩大 SELL-only beam。

Q25 当前约 2605.7、v3 约 2397.8 的两个 rating 快照来自不同的对手/时间队列，本文没有同分布在线随机对照，不能把约 208 点的 rating 差直接归因于 v3 overlay，也不能据此证明它无害。

在这些数据出现前，把 v3 的 2400 线上成绩归因于“搜索本身失败”或“只需放大搜索”都过早。现有证据更支持：父模型对当前线上对手分布缺少近期开局和市场反应覆盖，而 v3 是一个窄局部改动，且没有改变确认面板的胜负。
