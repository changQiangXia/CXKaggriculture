# 中局法证（P0，cam30 线上 93 局，day8-27）

## 数据

* 样本：cam30（56685648）**93 局 = 57 胜 / 36 败**，逐日 telemetry；
* 探针：`midgame_probe.py`（每局逐日现金/雇工/买地/作物/动物/棚存/卖出量/价格）；
* 对照：loss vs win 的逐日均值与标准化效应量（Cohen's d）。

## 结论 1：物理动作几乎无差异

* 雇工/hires/买地/作物/动物/棚存/成熟作物：loss 与 win 的逐日差 ≤1（hands/hires=0）；
* 卖出量逐项相同（如羊毛 day14 均为 12.0、牛奶 day15 20.2 vs 20.7、草莓逐日相同）；
* ⇒ **败局不是"少种/少雇/少卖"，而是同样的动作在市场端实现更差**。

## 结论 3：差距来自市场实现（强敌砸价）

* **对手均分：败局 2,276 vs 胜局 1,979**（差 297）——败局几乎都是对上 2,200+ 强敌；
* 高价值品价格（loss − win，day14-20）：
  * 羊毛 **day14 −38.6、day15 −35.9、day16 −32.0**；
  * 牛奶 day14 −14.5 → day20 −8.6；
  * 草莓 day18 −12.1 → day20 **−26.8**；
  * 甜瓜/胡萝卜反而略高（+2~+7）——非争抢品。
* 卖出量相同、价格更低 ⇒ **强敌（cow+sheep 家族高段位）在同一窗口抛售 MILK/WOOL/
  STRAWBERRY，压低我们同批货的实现价**。

## P1 候选假设（按预期收益排序）

1. **高价值品抢跑（首选）**：把 WOOL/MILK/STRAWBERRY 的卖单前移到价格崩塌前：
   * 羊毛：day13-14 前移（day13 价 128-149 vs day14 价 61-100，12 单位差 ~0.8-1.2k）；
   * 牛奶：day14 前移（120 vs 84，~6-10 单位差 ~0.4-0.7k）；
   * 草莓：day17-18 前移（183 vs 157/130，~8 单位差 ~0.3-0.6k）；
   * 合计潜在 ~1.5-2.5k/局，与 day14-20 的资金差同量级。
2. **非争抢品倾斜**：甜瓜/胡萝卜在败局里价格更高（+2~+7），可微调销售结构；
3. **价格速度触发**：当 MILK/WOOL 价格日内快速下跌时提前出货（自适应版本，P1 之后）。

## 验证协议（P1）

* 先做**固定窗口抢跑**（每品种每天最多 1 张提前卖单，不挤占有计划的单）；
* 面板顺序：新鲜线上 184 局（两槽全部对局）→ fresh62/<2000 守卫 →
  b2000_2400 → 五池；胜场净 ≥0 且低分零干净回归才继续。

## P1 实验记录（2026-09-30 上午）

### FR1 · 固定窗口抢跑（羊毛 day13 / 牛奶 day14 / 草莓 day17）

* 在 184 局新鲜面板上**完全 no-op**（119-65 不变、0 margin 变化）；
* 调试单局（ep115392785）发现：**棚存在窗口内始终为 0**——base 是"到货即卖"，
  且强敌的砸价发生在我们货物到手之前（day12 中午羊毛价已从 ~119 砸到 61）。
  ⇒ 没有库存可抢跑，路线不成立。

### FR2 · 到货即卖 + 价格地板（day10-22，羊毛≥90/牛奶≥70/草莓≥120）

* 184 局：**胜负 119-65 不变（0 翻转）**，但 margin 平均 **−57**（>+50 仅 13 局，
  <−50 有 52 局）→ 提前出货反而轻微劣化，否决；
* 结论：base 的卖出时序已经在局部最优附近，"卖得更早"不是有效杠杆。

### 下一步（P2）

* 生产时序/结构：把高价值品提前（更早的羊/牛节奏）或以非争抢品（甜瓜/胡萝卜）
  为主——but 需重改生产计划，风险高，先做小范围参数试验；
* 需求/库存侧：按共享市场库存（需求剩余）择时，而非固定价格地板；
* 强敌（2,276）同族对抗：sell-lead/front-run 已有机制已调优，边际空间有限。

## P0-补 · 第二轮法证（2026-09-30 10:00-10:50 北京）——结论修正

第二轮不再只看"我们"的 telemetry，而是**把回放里双方的动作流、现金流入流出、

⇒ **"强敌产出流更高"不成立**；双方是同一种机器的同一档产能。

### 追加结论 3：终局没有任何可回收残值

第 719 步终局盘点（每局）：我方棚存 0.0、随身 0.0、成熟未收（动物/作物）0.2/0.0；
对手 0.1/0.1、0.4/0.7。⇒ 终局清仓已是满分，**没有"货没卖完"的漏**。

### 追加结论 4：差距 100% 落在**后段（d20-29）的资金净流**

把双方现金的正/负跳变按三段拆开（每局均值）：

| 段 | 我方净（败/胜） | 对手净（败/胜） |
|---|---|---|
| d0-9 | −603 / −260 | −807 / −532 |
| d10-19 | +45,329 / +49,079 | +45,592 / +45,616 |
| **d20-29** | **+46,571 / +50,174** | **+51,893 / +47,391** |

* 败局全期净差 −5,382，**其中 −5,322 全部来自 d20-29**；
* 对应地，对手后段的**毛吞吐**远大于我们：流入 84.0k vs 49.3k、流出 32.1k vs 2.7k
  （胜局对手：流入 63.7k、流出 16.4k）——即"谁后段还在市场里翻搅"与胜负高度相关；
* 对手后段多出来的支出几乎全是**买小麦**（d20-29 约 846 件 / 24-35k，我们 3.5 件）；
  但同理我们全期也买了 1,505 件小麦（63.5k）用于喂养——**这是双方共有的"麦循环"**，
  只是强敌把循环做得更大。
* 小麦价格路径（93 局中位）：d0 28 → d16-20 41-42 → d28 39；日内价差不足以支撑
  独立套利（且仓位被 shed=100 卡死）。

### 追加结论 5：我们收入的"世界敏感度"高于对手

全期现金流入（每局）：

| 组 | 我方 | 对手 |
|---|---|---|
| 我们败 | 167.6k | 176.8k |
| 我们胜 | 185.0k | 176.5k |

⇒ 对手的收入几乎不随对局/世界变化（176.5-176.8k），我们的收入摆动 17.4k。
我们赢得多的局，是"市场价格对我们友好"的局；对手是**不依赖世界运气**的稳定机器。
这可能就是"同产能却稳定赢我们"的根因：他们在坏世界里也能把同样的产出换成钱。

### 已判负/已闭线（勿重开）

* 产出流节奏（收获/复种/采集）——本轮证伪：双方逐项打平；
* 卖货时机（更早/更晚/拆单/留仓）——已闭（FR1/FR2/ts/td 四连）；
* 小麦采购择时（WT）与收官饲料守卫（FG/FG2/FG3）——旧报告已判负，本轮证据（双方
  都在做更大的麦循环）不足以推翻；
* 终局清仓、喂食/照料、化肥分配（草莓各 62 次）——逐项打平，无洞可挖。

### 对候选孵化路线的影响

在"物理产出 + 卖法 + 终局 + 喂养"全部打平的前提下，想提高 2000-2400 胜率，
只剩两条尚未被证伪的路：

1. **后段市场吞吐**（复刻强敌 d20-29 的麦循环规模）：已知 WT/FG 失败，但那些实验
   都发生在旧底座上；若要做，必须用"只在本局现金充裕且价格有利时加码"的严格条件，
   并在**新鲜 184 局面板**上先验收；
2. **世界/需求自适应**：对手收入不随世界摆动，说明其组合能对冲"某品砸价"，我们
   的收入摆幅 17k —— 这是唯一还没被实验证伪的结构性差异（代价：需要动生产/销售结构）。

## P0-补2 · 强敌"后段翻搅"的最终定性（2026-09-30 11:45 北京）

上一节猜"强敌靠后段麦循环赚钱"——本轮用**逐笔成交价**把它测死了：

* 每局小麦流向（我方 / 败局强敌）：买 1,505 / 2,175 件、卖 1,721 / 2,535 件、
  **喂养 327 / 342 次**（几乎相同）、收获 515 / 578 件；
* 逐笔成交均价：对手全期**买 40.91、卖 39.29**（后段买 41.15、卖 38.88）——
  也就是他们的麦循环**是负价差的**，纯属噪声交易；
* 日内小麦价差均值仅 **1.08 元**（价格曲线在 I0 附近极平：25-45 覆盖 400 件）。

⇒ **结论：后段"多出来的 35k 毛流水"不是收入来源**，它被同等规模的买入抵消。
真正的差距回到**产出端**：后段收获件数 840（我们）vs 896（强敌），差额集中在
小麦 +31、番茄 +24、蛋 +18 件 ≈ **+2.9k/局**，加上前段同类差额 ≈ 全部 5.3k 缺口。
而"多产一点"在我们的路线设计里被两件事卡死：**农场只有 3 象限（75 格，全满）**
和**劳动力排满**（见 A31/A32）。
