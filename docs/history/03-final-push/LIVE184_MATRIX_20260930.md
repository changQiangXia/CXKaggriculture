## 2. 这张表最重要的结论：**面板在 ±2 个净翻转以内不可信**

* 面板说 `snk6_tl_gate2` 比 cam30 净 **+1**（且 <2000 段 30-0 更好）；
* 线上 6h 实测却是 **cam30 2274.1 / 61.3%** vs **gate2 2208.8 / 53.8%**，2000+ 段
  53.8% vs 44.7% —— 面板的排名与线上相反。
* 推论：本地新鲜面板可用于**淘汰**明显更差的候选（−3 及以下），
  但**不能**用来在 ±1~2 的差距上选优（与"gate2 本地优势未迁移"的旧结论一致）。

## 3. 对孵化路线的影响

* 今天扫过的 18 个变体 + 3 个老候选，**没有一个在胜场口径上真正超过 cam30**；
  所有"看起来 +1"的（ca_buf12 / gate2 / gate2b / cm22）不是被线上证伪，就是无法在池间复现。
* 唯一还没被证伪的差距仍然是"**同等产出下，强敌把更多件数变成钱**"（小麦+63、蛋+34、
  番茄+27 件/局），而加法类改动全部被"农场已满 + 劳动力排满"挡住；
  要动它必须重排整盘计划（建造-搬运-放置链 + 劳动分配），属于结构性重写。
