* 对手分布几乎相同（均分 2,094 vs 2,075）；<2000 双方 15-0；
* 主战场 2000-2400：cam30 54% vs gate2 46% → **cam30 更强，基线回退 cam30**；
* 配对反事实（78 败局并集）：cut 救 16 / 吐 14（净 +2）；
* 差异不显著（p≈0.40/0.26），但方向一致。

### 1.2 败局结构（78 个败局并集）

* **48 局双方都输（结构性损失，61.5%）**；16 局 cut 可救、14 局 cut 有害；
* 终局法证：败局在 day25 已落后 ~1.7k，根源在中局（day10-25）复利；
* 终局执行无异常（雇工/棚存/卖出量与胜局近似相同）。

### 1.3 已穷尽的机制（不再重复）

* CA_MARGIN −22 平/−15 劣；CA off −65/−51；
* 506–527 无对应损失；回补 −15/−14；cut1 −62/−34；峰值 +1 雇工被守卫否决；
* fs2 no-op；ML 学习门不可预测（AUC≤0.55）；原型识别退化（726/728 cow+sheep）；
* gate2b：13 面板去重 raw +3/clean +4，但线上未体现优势。

## 2. 计划目标

1. 把 cam30 在 **2000-2400 段的胜率从 54% 提到 ≥58%**（银牌冲线关键）；
2. 保持 <2000 段 100% 防守；不改动已验证的强项（CA 结构、终局清算）；
3. 用**新鲜线上败局**（150 局新料）作为主证据源，旧磁带池降为辅助；
4. 产出 1 个可提交候选（若无可信候选则不提交）。

## 3. 工作流

### P0 · 中局法证（day10-25）——立即开始

* 对象：78 个败局 + 同批胜局（对照），逐局记录 day10-25 的：
  现金/雇工曲线、买地时机、作物结构、按品卖出量与价格、棚存；
* 方法：扩展 `endgame_probe.py` 到 day10-25（或新写 `midgame_probe.py`），
  对比败局 vs 胜局的逐日差异，按效应量排序；
* 交付：`MIDGAME_FORENSIC_20260930.md`——前 3 个系统性差距 + 对应假设。

### P1 · 候选实现（从法证结论出发）

针对 P0 的前 3 个差距各实现一个最小层（一次只改一处）：

* 候选形态：cam30 + 单层（雇工/买地/卖单时机/作物结构之一）；
* 验证顺序：
  1. 新的**线上败局面板**（78 局，含对手磁带与胜负标签）；
  2. fresh62 + <2000 守卫（零干净回归一票否决）；
  3. 五池 + b2000_2400 主战场面板（必须 ≥ cam30）；
* 若 P0 未发现可行动差距：转向 P2。

### P2 · 强 cow+sheep 家族（2055+）的对抗

当前生态 99.7% 是同开局；cam30 对 2000+ 只有 54%。

* 方向 A：**卖单前置**（在他们 MILK/WOOL 抛售前出货）——用 78 败局标定其卖出时点；
* 方向 B：**生产结构微调**（strawberry/melon 占比，按 2600+ 带画像）；
* 方向 C：mirror/准镜像识别后的专门策略（已有分类器可复用）；
* 每个方向时间盒 2h，无净胜场立即淘汰。

### P3 · 验证协议（所有候选必过）

* 主判据：胜场净 ≥0（全部面板）+ 2000-2400 ≥ cam30 + <2000 零干净回归；
* 配对同种子；clean-both 口径；跨池留一；
* 新料优先：150 局新回放构成的"新鲜面板"是最终守门员；
* 失败一律写入 `NEGATIVE_RESULTS`。

### P4 · 提交与守槽

* 默认保持两槽（cam30 + gate2）；**不轻易动用配额**；
* 仅当候选通过 P3 全部判据时才建议提交（需批准）；
* FIFO：下一发顶掉较老的 cam30 槽；最后有效提交 ≤ 09-30 22:00 北京；
* 若提交新候选，建议用其替换 gate2 系列（cam30 保持不动）。
