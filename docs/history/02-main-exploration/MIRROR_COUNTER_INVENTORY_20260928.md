# 镜像反制家底盘点（2026-09-28 15:30 UTC）

> 用户要求：仔细扫仓库，尤其是镜像反制经验。本文按"结论 → 出处 → 现状（代码在不在）→ 迁移到当前威胁"整理。

## 1. 核心结论（来自 `MIRROR_FORENSICS_20260925.md`）

1. **镜像表现是 SN_H 的阶跃函数**：同一批 96 种子（192 局）对 archplus——
   SN_H=48 → **−77/局**；SN_H=8/12/16/20/24/32/40 → **−140…−290/局**（全塌）。
2. **candidate_final 的 −289 镜像亏，全部来自 SN_H=8 这一个旋钮**；把它回退到 48（其余 5 个旋钮保留）
   → **+54.4/局（t=3.63，53胜/19负）**，且该配置在 4 个外部强对手上同时为正（+62.9，t=2.98）
   —— 第一个"镜像与强池双正"的配置。
3. **机制**：SN_H 是"把未来计划的卖单提前到本回合"的窗口。**同血统对局是价格战，先卖者赢**；
   SN_H=8 = 卖得比对手晚 ⇒ 被压价。对外部弱池，提前卖=自己砸价，所以冻结磁带池反而显示 +536（假象）。
4. **往长扫更好**（160 种子）：SN_H=64/72/96/120 → 镜像 +17/+32/+34/+35（先卖越早越好）。
5. **标定**：镜像 −289 ↔ 线上 −98 分 ⇒ **≈0.34 天梯分 / 镜像点**（这是唯一被线上锚点校准过的换算）。
6. **镜像护甲把同族差异压成 0**（`LADDER_CALIBRATION` §9：h120ch99 vs m2 32 种子双座全平）
   ⇒ **血缘内 h2h 不能用来选候选**，必须用血缘外活体对手。

## 4. 迁移到当前威胁（V4/V76 公开系，占我们 37% 对局、胜率仅 61.9%）

公开系是**价格战型家族**（小麦/肥料高周转），而镜像经验给的正是价格战规则：**先卖者赢**。
因此：

* **M1（门控窗口）**：把 `_or2_sn_h` 护甲移植到当前 sn48 底盘，但门控改为**家族指纹**：
  `对手=V4 系（开局指纹）或 r37_similarity≥0.9 → SN_H=120；否则维持 48`。
  预期：在 V4 系子面板（546 局 / 其中 ≥2000 396 局）上净正，且全局面板不劣化。
* **M2（子面板上重扫窗口）**：现有全局扫描（≥2400）给出 48 最优；但**镜像/价格战对手偏好长窗**。
  在 V4 系子面板上单独扫 SN_H ∈ {48,64,96,120,240}，看是否出现"家族专用长窗"。
* **M3（护甲自保）**：我们线上两槽 56628338/56629633 是近亲拷贝；若天梯出现自家对撞，
  EXP288/`_R44` 护甲必须生效（当前已在 sn48 底盘里，需回归验证）。
* **M4（换算）**：用 0.34 分/镜像点把子面板收益折算成预期天梯分，作为候选排序的辅助口径。
