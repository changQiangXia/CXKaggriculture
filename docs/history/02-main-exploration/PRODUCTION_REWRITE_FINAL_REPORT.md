# 生产端整盘重写：结项报告（2026-09-24）

## 目标（用户设定）

> 在 herdfix 底座上用新评估协议（自博弈面板 + 配座种子块 + 商店序列审计 +
> 未触碰 holdout）做生产端整盘重写，目标是孵化一个在重定义门（净胜/胜率口径，
> 废除"零负 delta"）下显著优于当前底座的候选；期间禁止任何 Kaggle 提交，
> 提交需另行明确批准。

## 结论

**未孵化出候选。** 在完整的可探索空间内，没有任何可获得的生产端改动能显著
优于当前底座；底座经验证强于整个公开区，唯一强于它的是不可获取的私有顶层
计划。经用户确认，**从零手写重建的成本远大于预期收益，本目标以此结项**。

## 新评估协议（本次建立，长期可用）

- `panel_selfplay.py`：配座自博弈评估器。每 seed 双座位各一场、两场为一个
  统计单元；双方都是活 agent，同一 kagsim 世界 ⇒ 商店序列天然一致，
  无冻结 tape 的商店重掷偏差（qeinstein 量化的 +6.6k/局）。
- 开发面板：16 DEV 种子 × 3 公开对手（mooman v48 / qeinstein moev2 /
  5thDimension public_router）× 双座 = 96 局/次评估。
- **未触碰 holdout：种子 101..112**（本目标全程未使用）。
- 底座基线：+4,156 / +19,941 / +30,876（三对手均值 +18,324）。
- 口径教训：**头对头胜 ≠ 面板胜**（非传递性，hedge=0 是实例）。

## 关键定量事实（供未来引用）

- 底座 vs 公开区：+4k（v48）、+20k（moev2）、+31k（pubrouter）；
  最强公开 agent（Kaito v58）对底座 −17.4k。
- 底座 vs 私有顶层（clean tape 口径）：DSM −20.5k、DECEM −12.8k、
  tetsuya −5.2k——**这是全部已知的"我方劣势"来源**，且不可获取。
- DSM 单局取证拆解：番茄 82 vs 0、蛋 58 vs 0、小麦 583 vs 444。
- 可移植性是稀缺资产：公开/顶层 tape 的存活率 1%（200 条里 2 条）。
- 底座内部：无净负层；路由后悔度 −158（已优于每格最优固定路由）。
