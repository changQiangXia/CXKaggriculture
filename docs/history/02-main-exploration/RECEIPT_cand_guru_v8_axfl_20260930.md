## 1. 缘起（用户提问：旧血统的好处理能否搬过来）

做机制清单差异分析：旧血统（snk6）有 **67 个常量 / 36 个函数**是 GURU 没有的。
逐个评估后选出第一批移植候选 `_AX` 家族（自包含的市场机制）：
* `_ax_price` / `_ax_shape` / `_ax_fib` / `_ax_simulate`——旧血统自研的**市场订单模拟器**
  （按引擎逐单位价格规则模拟一串订单的可行性与收益）；
* `_ax_frontload`——把市场单分成 A（真实卖）/ B（买入+洗单卖）/ C（其它），重排为 A+B+C，
  且**必须在 pressure=0/1 两种假设下模拟均可行**才应用（防破坏洗单链路）；
* `_ax_advance_sales`——把未来 1-2 步的 premium 商品卖单提前执行（旧血统默认关闭）；
* `_ax_r60` 生存守卫（旧血统默认关闭，本批不测）。

旧血统配置：`_AX_BUILD = {'adv': 0, 'fl': 1, 'r60': 0}` ⇒ 只有 frontload 是生产开关。
