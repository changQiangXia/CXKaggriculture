# `_OR2_SLOT_H`（槽位保留地平线）扫描：双门都通过的强杠杆

背景：2700–2800 段同局配对差分发现"赢家末期卖单槽 1.04/回合 vs 我们 0.91"。`_OR2_SLOT_H`
是控制"当卖单占满 10 槽时，为哪些商品保留位置、往回看多少回合"的常量——**不增加卖量**，因此
不受"静态池惩罚加量"的偏差影响（对照见 `NEGATIVE_MPX_20260925.md`）。

基底：`candidate_h120ch99`（SN_H=120、CXD=3200、CH_SHED=99），只改这一个常量。

## 3. 判读

* 与 MPX 的情形**不同**：MPX 是"镜像 +259 / 池子 −85"的符号冲突；`_OR2_SLOT_H` 是
  **镜像与池子同向**（都为正），因此属于"真杠杆"而不是非传递性假象。
* 因此 `_OR2_SLOT_H` 应作为新的候选轴：**20（池子最优）**与 **40（镜像最优）**都值得打包，
  前者风险低、后者上限高。
