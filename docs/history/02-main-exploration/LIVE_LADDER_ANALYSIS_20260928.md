## 3. 结论（对策略的三点影响）

1. **本地仪器要换主指标**：磁带池/对公开原版的 H2H 会系统性高估我们（因为测的是"公开基线"，
   而线上是"调优后代"）。新增两个主指标：
   · **close-game 胜率**（|margin| ≤ 1000 的局里赢多少）；
   · **活体对手面板**（V4/V76/idle/V53 作为 live agent，而不是磁带；脚本 `/tmp/live_h2h.py`）。
2. **"以公开家族为底座 + 嫁接我们的经验"是一条合理路线**（用户提议）：既然天梯是那个家族的
   竞技场，把我们的微算子（planner 窗口 SN_H/SLOT_H、镜像处理、终局卖单搜索等）嫁接到
   V4/V76 活体基线上，直接以"对 V4/V76 家族后代的胜率"为验收——打赢这个家族就等于上分。
3. **继续挖窄败**：把这 8 局（及后续新增）的对手动作序列与 V76 基线在同状态下的动作对比，
   找出"调优后代到底调了什么"——那就是当前天梯真正的得分点。
