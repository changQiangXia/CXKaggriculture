**结论**：**goal 的 M2 目标（day12 ≥70 株 / 4 象限，day18 ≥85 株）缺乏证据基础，建议改写或撤销。**
本文件给出全部反证数据；`candidate_final` 未改动、零提交。

## 0. 一句话

在 AM 全量语料（260 局）里，**我们与对手的日 6/12/18/24 生产结构逐局完全相同**（91–94% 三项全等、
配对中位差 0 株/0 动物/0 象限）；而"≥70 株"的结构在 260 局里**只出现 1–2 次**（且那 1 局就是
ep112558636 的 Fourth Quadrant）。**要重写的"目标结构"其实不是赢家的特征，而是一个孤例。**

## 3. 顺带修正的两个测量错误（避免误导后续）

1. **"对手卖单 +71%"是伪差**：早先用"棚存下降"当卖出，把 **PICKUP（棚→工人搬运）**也算了进去。
   修正口径（执行量 = min(下单量, 自身棚存或缺棚位)，按当步价计价）后：僵局里对手收入差
   **+27,537**（能翻组 +5,525），其中小麦 +17,658 收入 / +452 卖出 / +487 买入 —— 是**近中性换手**，
   不是净增益。
2. **"小麦往返可套利"不成立**：纸面回测两种规则都亏 ——
   绝对阈值（≤22 买 / ≥30 卖）：最好 +62/局、中位 0 笔；相对规则（EMA−ε 买 / EMA+ε 卖，6 组参数）：
   均值 **−89 … −277**/局。⇒ 市场有效，无可复制规则。

## 4. 那么真正的差距在哪（据现有全部证据）

* **同局配对**：对手 rating 中位 2,638 vs 2,588（僵局 vs 能翻）；
* **时间形态**：僵局是"我们早期领先（+2,131）→ day18 后失血"，能翻局是我们早期就不领先（+530）；
* **结构/行为**：91–94% 同形，产量（收获单位 1,393 vs 1,430）与照料次数相同，择时价格分位相同（0.32/0.50）；
* **三通道（bit-exact，残差 0）**：sell_d σ=+0.69、buy_d σ=−0.67（近似抵消）、fixed_d σ=−0.14。

⇒ 现有证据**不支持"生产端结构差"这一前提**；剩余差异是**小额的末期执行差**与**对手强度**，
而不是"我们没有大结构计划"。

## 5. 建议（请用户裁决）

1. **撤销/改写本 goal**：把目标从"结构 70+/4"改为**末期变现/执行差**（唯一在数据里可定位的通道），
   或直接把 AM 矿脉判为**已挖尽**；
2. 或者**放开线上数据**（`candidate_final` ref 56530265 的真实败局）——那是唯一能提供"新缺陷类"的来源；
3. 若仍要重写生产端，需先给出**证据支持的目标结构**（当前语料里找不到第二个这样的世界）。
