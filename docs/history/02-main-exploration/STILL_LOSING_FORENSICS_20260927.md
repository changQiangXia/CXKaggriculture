## 2. 路线头程：77% 的败局换一条已有磁带就能赢

对 96 局仍败局，把 41 条**已在包内**的 route 各强制一遍（整局语义）：

* 至少一条 route 能赢的局：**74/96 = 77.1%**；
* 神谕（每局取最优）：均值 **+3,631**（当前 −2,953）；每局神谕增益中位 **+2,880**；
* 最优 route 分布：110(19)、12(11)、10(11)、126(10)、103(9)…；
* 但**没有任何单条 route 能打平当前路由器**（最佳单条 47.5%/+1,023 vs 路由器 51.5%/+2,276）
  ⇒ 头程在"按世界选路"，不在"换一条路"。

### 2.1 先证伪"逐签名 argmax 表"
用一半局拟合"商店签名→最优 route"、另一半验证：**稳定性只有 1/8**（n≥8 的签名里 7 个两个半样本选出不同 route）
⇒ 直接在 29 个签名上取 argmax = 过拟合，不可用。

### 2.2 真正的信号：YARN 世界（真实语义下 +1,144/局）
