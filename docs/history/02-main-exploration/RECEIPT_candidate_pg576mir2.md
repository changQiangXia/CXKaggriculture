# 收据：candidate_pg576mir2（零劣化帕累托候选）

## 机制（一句话）

OR2 的"预约卖出"窗口在**真实对手**上应当缩短（后段预判失准会压低我们的卖出时序），
但在**镜像/近镜像对手**上必须保留（预判完全正确）；用"结构与现金都相近"的在线判据做护甲，
只在非镜像局的后段（step ≥ 576）把 `_OR2_SN_H` 从 120 切到 8。

实现（相对 CH99 两处）：新增 `_or2_sn_h(obs)`（定义在 OR2 层之前，保证模块最后一个 callable 仍是 agent），
并把 OR2 预约循环的 `_OR2_SN_H` 换成 `_or2_sn_h(observation)`。
护甲判据：双方 (作物数, 动物数, 象限数) 完全相等 且 |现金差| ≤ 2000 ⇒ 视为近镜像，返回 120。
