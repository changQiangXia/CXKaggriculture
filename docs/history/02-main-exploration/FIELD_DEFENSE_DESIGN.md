# 线上对手分布普查与防御性模型设计（2026-09-20）

## 1. 全量对手普查（两个线上模型全部对局，266 局）

| 家族 | 占比 | np_farm4（V50系）胜率 | timed174（farm2945系）胜率 |
|---|---|---|---|
| farm2945 系（[BUY20,SELL15]+17k磁带） | 29.8% | **39.3%** | 66.7% |
| V 系（[BUY7,SELL2]） | 34.7% | 92.6% | 80.0% |
| other（未分类） | 30.6% | 62.1% | **84.6%** |
| trade 型 | 2.3% | 0/0 | 83.3% |
| V_old | 2.3% | 1/1 | 80.0% |

结论：np_farm4 的病根 = 最大单一家族（farm2945 系，~30%）上只有 39.3%；
timed174 对**每一族都 ≥66.7%**。当前线上环境的真实分布与本地 375 旧池
（V 系时代权重）不同——两个评测面打架，必须以线上分布为准。

## 2. 时间序列与未来几小时估计

- 小时级噪声大、无稳定趋势、无重复对手（无单一对手连续狙击）。
- 最近数小时：np_farm4 的对手里 2945 系升至 30~50%；timed174 的对手里 V 系
  间歇性高发（某小时 9~11 局）。
- 估计（防御性）：未来几小时保持 ~30% 2945 / ~35% V / ~30% other / ~5% 其他，
  但任一族的占比可能小时级摆动到 50%。

## 4. 防御性设计：单底盘 + 谱系门控参数表（farm2945 底座）

硬双底盘切换已判不可行（step-0 耦合）。但 timed174 与 milk_all4 是**同一个
底盘、只差 43 行 margin 表**，可以在运行时按指纹切参数，零状态机风险：

- 对手=2945 系 → **milk 表**（四种动物产品回原生门槛，其余 flood）：镜像族
  89.8%、对 15 个线上赢家 73.3%。
- 对手=V 系 → **aggr 表**（全商品 flood）：timed174 对 V 线上 80%、本地 63%。
- 对手=other/trade/未知 → **timed 两阶段表**：线上 other 84.6%、trade 83%。

指纹（farm2945 底盘视角，我方 step0=[BUY20,SELL15]）：step1 现金差 dm=0 →
2945 系；dm=+6 → V 系；其余 unknown。分支互不干扰，任一分支单独退化不会拖垮
其他分支——这就是对分布估计失误的防御。

预期（现分布）：0.298×0.78 + 0.347×0.70 + 0.306×0.846 + 0.023×0.83 + 0.023×0.80
≈ **77%**，且三种偏重场景都在 ~70% 以上。

## 6. 冲 90% 的进展与约束（第二轮）

### 6.1 关键发现：other 里藏着大量 2945 变体

对 other 家族做深分类：~60-70% 是 farm2945 底盘的改开局变体（[BUY5,BUY1]/
[BUY35,SELL30]/[BUY13,BUY30,SELL30]/[BUY15,SELL10]…，同样的 17k 卖单磁带 +
step1 COW2/SHEEP2），只因开局非标准而漏进 other。真实 2945 系占比 ≈ 48%。
把 soft_m0 的指纹扩展为"步-1 (现金差,小麦价) 联合签名"（dm ∈ {−6,−10,−20,−4,+1}
且小麦 28 → 2945 系）→ **soft_v2**，多覆盖 11/53 场。

### 6.2 判据更新（EV）

| 模型 | EV |
|---|---|
| **soft_v2** | **81.0%** |
| timed174(live) | 77.3% |
| soft_m0 | 74.0% |
| farm_gated | 68~71% |
| np_farm4(live) | 65.1% |

敏感性：soft_v2 在 V 偏重 84.1%、other 偏重 82.3%、全 V 94.4% 均最优；
2945 偏重 75.4%（次优）。

### 6.3 绑定约束（为什么 90% 很难）

EV = 0.478×w(2945) + 0.347×0.969 + 0.126×0.85 + 0.046×0.7。
即使其余家族全满分，EV 上界 ≈ 0.478×w(2945) + 0.522。当前 w(2945)=61.8%
→ 上界 81.7%；要到 90% 需要 w(2945) ≈ 89%。已扫：farm lead 0/2/4（4 最优）、
milk 表（无差异）、lead0/2（更差）。61.8% 是当前 V50 底盘的局部平台，90%+
需要全新的 2945 反制机制，尚未找到。

### 6.4 2945 支的全旋钮扫描（61.8% 是硬平台）

| 旋钮 | 结果 |
|---|---|
| 预留价格门槛 margin 0/floor 1.0（soft_m0） | **61.8%（最优）** |
| margin −100/floor 0.5 | 47.7% vs timed174、fresh62 中性 |
| farm lead 0 / 2 / 4 | 35.3% / 50.0% / **61.8%** |
| milk 表（动物产品原生+其余 flood） | 61.8%（无差异） |
| ADV 层价格门槛（低价不抢卖） | 35.3%（负） |
| 预留视野 cap 6 | 50.0%（负） |

结论：61.8% 是 V50 底盘对当前 2945 赢家的局部最优；90% 需要 w(2945)≈80%，
现有机制均达不到。已知硬上限 ≈82~85%。
