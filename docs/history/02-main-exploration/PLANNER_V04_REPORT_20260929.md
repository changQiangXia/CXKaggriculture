## 2. 这轮真正踩掉的坑（可复用教训）

1. **静默失败死循环**：对未成熟作物发 HARVEST 是 no-op，工人在同一格反复空收，
   第一天就能锁死全队。修复=收获必须 `age >= first_yield`。
2. **仓库里的动物不产出**：`BUY_ANIMAL` 只进 shed，没人去 BUILD/FETCH/PLACE 的话
   现金全变死库存。修复=BUILD/FETCH 提到 prio 12，且买入受"空栏位数"约束。
3. **种子库存重复扣减**：缺口写成 `target - tiles - seeds` 后，31 颗草莓种子只
   算出 1 格缺口。修复=缺口只看 `target - tiles`，种子只做单步上限。
4. **DROP 会把随身小麦一起丢光**：改成 `PLACE <item> <n>` 只放指定商品，
   喂食连续性问题随之消失。
5. **卖单挤占 10 个市场槽**：全品类每步挂卖会把 BUY_SEED/BUY_ANIMAL 挤掉。
   修复=高价值卖→雇工→买动物→买种→买地→低价值卖→买饲料的顺序。
6. **浇水存活判定**：`consecutive_unwatered>=1` 当天不浇就变杂草 → prio 13，
   高于 CARE/收集；窗口内浇水 prio 11。

## 4. 与强者的差距定位（下一步主要矛盾）

* 强者终局 ~130k；我们 48k。差距不在"愿不愿意买"（结构已同型），在**执行密度**：
  - 我们 11 手时每个工人每天只完成 ~5 个真实动作，其余在走路上；
  - 分区偏好（±60）+ 贪心匹配只是缓解；缺的是**日路线预排/任务串（TSP 近似）**；
  - 中后期一旦动物到 13 头，FEED/CARE/COLLECT 把工位吃满，第三优先的
    PLANT/WATER 开始掉线（终局只剩个位数作物）。
* 尚未移植/试完的旧线（下一 goal 的允许方向）：
  1) TSP/分区驻留式劳动预排（本轮最大缺口）；
  2) 商店世界条件早承诺（YARN→羊毛、BAKERY/BRUNCH→蛋、PIZZA/冰激凌→奶/草莓）——
     新血统可以直接读 `town.unlocked_shops` 改变动物/作物结构，磁带做不到；
  3) 对手供给冲击预测（对手 hires/新增栏位 → 提前卖高价品）；
  4) 高周转卖侧（按当日需求/价格相位分批出货）；
  5) 镜像局政策（新血统暂不涉及，等 M2 再说）。
