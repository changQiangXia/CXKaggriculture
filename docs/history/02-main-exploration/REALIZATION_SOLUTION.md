# 变现最优控制：模型上的解（2026-09-24）

## 问题形式化
- 共享市场：每商品一个库存 I，价格面 p(I) bit-exact（market_model.py）。
- 每步 10 槽、逐单位锁步：同槽同下标双方报价同一快照、按玩家序提交，
  故**同一步的镜像卖单实现相同单价**——相对胜负只可能来自"步级"时机差。
- 我方自由度 = 每个已计划卖单的**执行步**（数量不变、终局 718 前清仓）。
- 对手卖出流：冻结 replay 可观测；实盘不可见、只能预测。

## 闭式决策律
对商品 X 的一单位计划卖单，若把执行从步 t 移到 t′：
- 单价变化 ≈ Σ_{k∈(t,t′]} [对手净供给(卖−买) − 需求] × |dp/dI|；
- 故 **对手净供给流 > 需求 ⇒ 越早越贵（前插），反之越晚越贵（后置）**；
- 前插的可行域受 **shed/生产时刻** 约束：商品没产出时想卖也卖不了。

## 可达性拆解（21 局、607 个跟卖事件）
- 滞后分布：0 步 351、1 步 102、2 步 46、3 步 63、4 步 45。
- **58% 是同回合镜像**（对手 dump 时我方同价卖出）——无相对优势可挖。
- 对手 dump 当步我方**有货可前插**的事件仅 86 个（lag≥1 且 shed 有货）。
- 神谕上界 +58,083 因此大部分物理不可达：要么同回合（锁步同价），要么
  我方当步无货（生产滞后）。

## 结论
- 共享库存-价格动力学下，我方最优变现控制器在 21/107 败局语料上
  **= base 本身**：其卖出节奏已把"生产允许内最早/需求恢复后"两个方向都
  占住；任何步级扰动都是零和（tape 赢一点、镜像输一点）。
- Phase 3 四门的"107 零负 delta + 镜像 90 零负板"要求严格占优，等价于
  存在一个处处不劣于 base 的非平凡改动——上述证据表明它不存在。
- 未开发预算在**生产/固定成本结构**（雇佣节奏、小麦产能、买端时机），
  不属于变现控制器的自由度。

## 第九条：同回合槽位重排（2026-09-24，66 局新败局，多样对手池）

公开区最新热点粒度：在同一步内重排我方 SELL 槽位，利用逐单位锁步的价格
路径。口径 = 66 场最新败局（snh48 38 + am 28，0 镜像、44 个不同团队），
bit-exact settle_step 反事实，目标函数 = 我方收入 − 对手收入（价差）。

- **神谕上界（完美预知对手当步订单）**：合计 +87,069，均值 +1,319/局、
  中位 +437/局、最大 +4,679/局，66/66 局 >50。收益集中在
  MELON/FERTILIZER、WOOL/FERTILIZER 等交错步（单步最高 +1,451）。
  ⇒ 机制的天花板真实存在，且是本项目测过的变现机制里最大的。
- **quote-priority 启发式（r37，公开状态可算）**：66 局合计 −1,561，
  均值 −24、22/66 为正 → 拿不到天花板，≈0（噪声）。
- **自模型最优响应（k17 打法，假设对手=自己）**：66 局合计 −66,096，
  均值 −1,001、32/66 为正但负尾极肥（单局 −4,944）→ 在多样对手池上
  **主动自伤**，k17 审计预言的"clone 专用 exploit 出族失效"在我们语料
  上以直接数字证实。
- 天花板与策略之间的缺口 100% 在**对手当步订单预测**：该订单在决策时刻
  不可见（同回合锁步），与 §相位锁定 的"卖出流预测不可达"同一条腿闭环。

结论：变现线在最细粒度（槽位级）也收口——**机制存在约 1.3k/局的真实
天花板，但没有任何不依赖对手订单预测的策略能拿到它**；两个公开策略
一个 ≈0 一个 −1k。`base` 仍是变现控制器的最优解。
