1. **本段位无结构差**（9/20–26，n≈9.4k 席）：2300–2600 与 2600+ 的赢家/输家在
   crew(12.3/12.3)、hires(275)、首日购地(6.00)、tiles(241)、plants_*（含番茄 ~2）
   上全部 |d|≤0.10 ⇒ 胜负靠微执行，不靠作物/劳动结构。
2. **回放新鲜度上限**：9/27 之后几乎没有回放（0.1%），9/28 完全缺失；
   对手分析只能用 ≤9/26 的窗口，且需标覆盖率。
3. **完成度过滤**：我们 ~9% 的胜局来自"把冻结对手饿死"（fid<0.95），
   所有面板一律用 fid≥0.95 口径复核。
