# SLOT_H 前沿：镜像 ↔ 低段安全（分期门控，2026-09-25 夜）

## 0. 背景

用户要求"**低分局零闪失**"。此前已知：
* 高 `_OR2_SLOT_H` 让镜像变强（sloth80 +385.9 vs ch99 +54.7）；
* 但线上 sloth80 在低分段出现 ch99 没有的失误（前 19 局 3 败 vs 0 败）。

新工具：**低分段池** `pool_georgy_band.py`（georgy 语料里双方评分 1400–1900 的真实对局，
冻结强侧动作带、同 seed 重放、多臂配对）。**它复现了线上排序**：ch99 > s20 > s80。

## 1. 亏损的定位（60 局逐日收入）

| 窗口 | ch99 | s20 | s80 | Δ(s20) | Δ(s80) |
|---|---:|---:|---:|---:|---:|
| day 0–16 | 完全相同 | 完全相同 | 完全相同 | 0 | **0** |
| day 16–20 | 22,516 | 22,516 | 22,499 | 0 | −16 |
| day 20–24 | 20,329 | 20,308 | 20,274 | −21 | −56 |
| day 24–28 | 17,706 | 17,674 | 17,651 | −32 | −54 |

⇒ 高 horizon **只从 day 16 起**改变行为，且**只在末期亏钱**。

## 2. 分期门控（`make_phase_gate_arm.py`）

直接补丁槽位逻辑的两处读取点（`_pg_slot_h(step)`：前期值 / 末期值，切换点 step 480），
避免 wrapper 造成的层递归。测得：

| 配置（前期/末期） | 镜像（257–768, n=512） | t | 低段 Δ vs ch99 | 判读 |
|---|---:|---:|---:|---|
| ch99（8/8） | +54.7 | 7.2 | 0（基准） | — |
| **pg_early80（80/8）** | **+106.9** | 12.4 | **−9.0（t=1.7，不显著）** | **前期 horizon 几乎免费** |
| pg_e80l12 | +135.7 | 12.9 | −42.7（t=5.3） | |
| sloth20（20/20） | +203.5 | 16.6 | −56 | |
| pg_e80l20 | +243.3 | 19.7 | −80.0（t=7.3） | |
| pg_e80l40 | +310.2 | 22.3 | −83.1（t=7.0） | 支配 l20 |
| pg_late80（8/80） | +336.1 | 20.9 | −100（t=7.4） | |
| sloth80（80/80） | +385.9 | 23.6 | −102（t=7.4） | 线上已交 |

**结论**：镜像收益与低段亏损**同源、同在末期**；把大 horizon 只用于**前期**（step<480）可以
拿到 +52 镜像而低段只付 −9。
