## 6. 下一旋钮（同层、同"端点"问题）：`V9_RACE_DEFAULT` / `V9_RACE_MAX`

**先在扫之前写死设计**（2026-09-28 20:15 CST）：

* 语义：`horizon = min(V9_RACE_MAX, max(V9_RACE_DEFAULT, lead + V9_RACE_MARGIN))`，
  `lead` = 对手领先量。现役 = DEFAULT 80 / MAX 96 ⇒ **96 是 `V9_RACE_MAX` 封顶**，
  与 SN_H 上一轮"卡在端点"是同一个病。
* **双因子设计**（避免单维走到端点）：
  DEFAULT ∈ {64, 80, 96, 128} × MAX ∈ {96, 192}，共 8 臂（含现役 (80,96) 作锚）。
  理由：不释放 MAX 就分不清"DEFAULT 最优"与"被 MAX 卡住"。
