# 反事实评估协议（2026-09-24，商店 RNG 审计后修订）

## 1. 已核实的事实（引擎源码 kaggriculture.py 1.32.7）

- `_end_of_day` 里 `rng = random.Random((seed * 1_000_003) ^ day)`：每天
  一个按 (seed, day) 固定的随机流。
- 该流先被 **weed 生成**消耗：每块空地 `rng.random()` 一次（无论是否
  长出），随后商店解锁 `rng.choice(SHOPS)` 一次（每 3 天一次）。
- ⇒ **我方候选改变某天终局空地块数 = 后续商店解锁序列整体位移**。
  冻结对手 tape 反事实里，对手可能正在执行"为另一个世界写的计划"。

## 2. 审计结果（shop_audit.py，66 局，2026-09-24）

- 双 tape 回放 kagsim.Game(seed)：终局双方现金 66/66 与原局逐分相等，
  商店序列 66/66 相等 → 回放约定与引擎确定性成立，反事实地基可靠。
- 本地候选（变现层默认开关）替换我方、对手 tape 冻结：商店序列 66/66
  与原局相等 → **只动 market 单的变现层改动不扰动世界**，现有 Phase 2/3
  的 tape 反事实结论不受此坑影响。

## 3. 分层协议

### 变现层改动（只改 market 单，不动 farmer/hands）
- 继续用冻结 tape 反事实（kagsim 或 market_model 单步重放），安全。
- 每个新改动的抽查：候选局终局商店序列 == 原局（shop_audit 的口径）。

### 生产层改动（动种植/动物/地块/雇佣）
- **禁止**直接沿用冻结 tape；候选会改空地块数 → 商店重掷 → 比较的不是
  同一世界。
- 正确协议（按公开区共识 + 本坑）：
  1. **双方都动的自博弈 / 固定对手 agent 面板**（对手是函数不是 tape）；
  2. **配座种子块**：同一 (seed) 双方座位各打一遍，作为一个统计单位；
  3. **未触碰 holdout**：调参期间不看的 seed/对手块，只在终审用；
  4. **商店序列一致性**：kagsim 逐局记录每天 town.unlocked_shops，任何
     依赖原局商店的对照（如 replay 面板）都要先验证序列未变，变了就
     视为不同世界、不可直接比 margin；
  5. 面板按家族分层报最差族分，不只看均值（nihilistic 的
     worst-family-first 序可抄）。

### 偏差量级（qeinstein 独立测量，2026-09-24 收录）

- 未钉商店的 tape 反事实 harness：**+6,613 币/局、11 局战绩的系统性高估，
  方向永远偏向"会读商店的自适应候选"**（候选适应新世界，冻结 tape 不能）。
- 钉商店后案例反转：Crop Dusta 6-3 +18,078 → 3-6 −1,286。任何"改了地块
  占用"的候选，在未钉店 harness 上的正 delta 一律按此偏差打折。
- 修法（qeinstein pinned_gauntlet.py）：每步之后把 `town["unlocked_shops"]`
  覆写回录制的序列，价格与商店需求即精确跟随录制世界；杂草仍会不同但
  影响小。若 kagsim 不支持状态注入，就用双方都动的自博弈面板，或自建
  Python 钉店回放。

### 结果口径
- 评分只认 P(win)/胜点；现金 margin 是诊断。样本量小的正 delta 一律
  按噪声对待（66 局里 3 个"翻正"即噪声级）。
