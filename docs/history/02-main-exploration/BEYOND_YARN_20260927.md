## 3. 还没试的维度（按价值排序）

1. **按对手开局资金选路（rkey）**：现有 `_V93_ROUTE_BY_RIVAL` 只映射了**一个** rkey→128
   （而 128 在 YARN 局是 −1,694）。回放里能取到 step2 观测，可扩成"rkey 分桶 → route"表；
   代价是要新探针 + 更多数据（现语料 198 局，分桶后每桶 n 会很小）。
2. **中盘重选（day 12-15）**：目前只在 day 6 选一次；若对手在中盘暴露策略，可再选一次。风险=过拟合，需要更多语料。
3. **异质合体**：不同世界/对手用不同底座臂（例如 YARN 世界用 s1sd_v2、非 YARN 用 am_v2）。
   已有逐臂分世界数据支持，但需要每局"选臂"的判据，且提交只能是一个包 ⇒ 需要把两臂打包进同一份代码（工程量大）。
4. **底座选择本身**：am/snh48 比 s1sd 在硬语料上高 +256~+284/局——这是当前最大的"免费"收益（已包含在 v2 候选里）。
