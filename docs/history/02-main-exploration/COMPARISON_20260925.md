## 3. 结论（三条，必须一起看）

1. **本地口径分辨不出线上强弱**：三个线上提交在本地全部落在 ±80 以内
   （AM 镜像 +77.7 / 强池 +23 / 公开池 +37 / 真实败局 +20 是本地最好的一只），
   但线上分数是 AM **2613.1** < snh48 **2643.8** < s1sd **2676.0**——
   本地最好的那只线上最差。**本地面板不能预测天梯分数**（天梯里有我们池子里没有的对手）。
2. **新保险层在本地必然显示 0**：它们只在"现金不足导致订单被拒"的状态里动作，
   而那些状态在我们的活体对手身上不会出现（镜像/强池/公开池全部逐场相同）。
   它们的证据只有两条：**触发态对照**（+6.2k ~ +11.0k）与**真实语料频率**
   （dawn 雇工缺口出现在 33.3% 的真实败局 / 13.0% 的胜局；买动物缺口 23.3% / 0%）。
3. **因此这三个候选是"天梯专属赌注"**：本地下行风险经实测为 0（逐场相同），
   上行取决于天梯里"抢钱型对手"的比例——这一点只有提交才能测。
