## 读法

1. **三只候选对当前线上包都是"窄负"**（−74 … −98），量级只有历史 candidate_final↔archplus（−289）的 1/3–1/4；
   按上面那条粗标定（0.03 分/局），对应线上风险约 **−2…−3 分**——远小于我们距 #100 的 +22 分目标之外的噪声。
2. `e2d_i` 的镜像亏最小（−73.8），`stack5` 与 `e2d_t_v224off` 几乎相同（−97.6 / −95.3）。
3. **vs s1sd 是 +5230、32-0**：s1sd 是旧血统（V54 栈），在活体对局里被当前血统全面压制；
   它线上 2676.0 与我们 2662.6 只差 14 分 ⇒ **再次印证"镜像/本地面板不预测天梯"**，这条数字不用于推断提交收益。
4. 结论：**没有任何一只候选在自博弈口径上"打不过"线上包到危险程度**；同时也没有一只在镜像上更好。
   选择就得靠别的证据（AM 靶场、外部池、机制）。
