## 0. TL;DR

1. `sweep_telemetry` 576 局：**0 个非零错误计数器、0 次底盘静默回退**，931 个计数器 548 活 / 383 静默 ⇒ merge6 无潜伏异常，D27 修复在规模上成立（477/576 局触发，811 次裁剪）。
2. **死开关**：`cfg.get("hold")` 读的键在全家族（merge6/archplus/h120ch99）**从未被赋值** → "d25 起抑制卖出"整段是死代码；而且历史反事实早已证伪它（hold=1：21 局 −527,677，全负），所以它死得对，不要复活。
3. **惰性机制**：六羊防逃 herd-fix 在 198 局硬语料里**一次都没触发**（配对差恰好 0.0）；DB 黎明现金 576 局 0 触发。二者是"无成本的保险"。
4. **R42 开盘是彩票**：`merge6 − abl_r42` 中位数 +6、108 胜 88 负，但尾部 ±78k、均值 −1,003（t=−1.56）。它改变了 196/198 局，是**高方差**而非系统性收益。
5. **D27 是唯一干净的正收益**：`merge6 − abl_d27` = 静态 +15.3（sd 13.8，t=+17.2）、硬语料 +17.3（sd 29.5，t=+8.25），**198 局里 163 局为正、0 局为负**（区间 +0…+382）⇒ 严格帕累托。
6. 优化产物：**`merge7` = merge6 − R42**（= 恢复 s1sd 开盘序列）。两个语料上都不劣于 s1sd，且保留 D27。

## 1. 语料判别力（本轮最重要的方法论发现）

| 臂 | 静态 0925 池（240 局） | **线上败局重放（198 局）** |
|---|---|---|
| s1sd | +151,439（基线） | **+3,013 / 胜率 56.6%（最好）** |
| archplus | — | +1,635 / 51.5% |
| merge6 | +151,458 | +1,273 / 46.0%（最差） |
| 配对 | `s1sd − merge6 = −19.2`（merge6 微优） | `s1sd − merge6 = **+1,740.6 (t=+2.42)**` |

**硬语料上的排序（s1sd > archplus > merge6）与天梯一致**（s1sd 2676 > archplus 2641），而饱和静态池给出相反答案。
⇒ 以后机制筛选应优先用败局重放语料；静态池只作不劣化门（与用户"静态对手只作参考"的判断一致，并且这次拿到了实证）。
