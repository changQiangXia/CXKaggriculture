# 异族硬池强化（2026-09-25 晚）

## 0. 动机

sloth80 在线上低分段（<2000）出现 ch99 没有的失误，且本地**强池**（4 个公开 agent）显示 sloth80 比 ch99 低 40.6/局。
需要一条能反映"**非克隆、且真能咬我们**"的评估轴。

## 1. 失败方案：仓库 agent 硬池（记录，避免重犯）

用 `opponents_scan2/3/4.json`（221 个自包含 agent 的 320 步扫描）挑出 **margin 最小的 32 家**建池
（`pool_diverse_hard.txt`，早期均差 +1,475…+14,845，看起来"最硬"）。

完整 720 步实测：**三家候选全部 100% 胜、均差 +89.7k** —— 早期咬人的 agent 在长局里会崩。
配对差 s80−ch99 = +71（t=1.53）、s20−ch99 = −18（t=−0.26）⇒ **没有区分度，方案作废**。

## 2. 有效方案：真实败局硬池（对手按构造就是硬的）

工具：`pool_live_losses.py`（新建）——取我们线上**真实败局**的回放，冻结赢家动作带、同 seed 重放，
多臂配对比较。数据：candidate_final 55 败 + archplus 54 败（共 110 局，含 2400–2800 各段）。

### 结果（110 局，双臂配对）

| 臂 | 均差 | 中位 | 胜率 |
|---|---:|---:|---:|
| ch99 | −2,150 | −690 | 23.6% |
| **sloth20** | −2,108 | −636 | 25.5% |
| **sloth80** | −2,105 | −655 | 26.4% |

配对差：

| 对比 | 均差 | sd | t |
|---|---:|---:|---:|
| ch99 − sloth20 | **−41.7** | 193.2 | **−2.26** |
| ch99 − sloth80 | **−44.6** | 339.8 | −1.38 |
| sloth20 − sloth80 | −2.9 | 282.3 | −0.11 |

### 判读

1. **池子有牙齿**：三家都输（均差 −2.1k、胜率 ~25%），不像仓库池那样 100% 碾压。
2. **两个新候选都优于 ch99（+42…+45）**，且 s20/vs s80 打平 ⇒ `_OR2_SLOT_H` 的提升在
   "真赢过我们的异族对手"上同样成立，不是纯镜像artifact。
3. 与**强池（4 个公开 agent）** 的结论相反（那里 ch99 高 52）⇒ 现有两条异族轴互不一致，
   说明"异族"不是单一维度：4 个公开 agent ≠ 天梯上真正赢我们的 110 个对手。

## 3. 建议：把"败局硬池"升为常设门

- 门槛：候选相对基准 **Δ ≥ 0**（配对、t≥1.5）；当前 sloth20/sloth80 都过（−41.7/−44.6 即 +42/+45）。
- 扩展：可加入旧 ref（56456489/56472390/56358950 等）的败局，把池子扩到 300–500 局、覆盖更多分段；
  等 replay 配额解除后，用 56547267/56547262/56554545 的新败局（含 <2000 段）继续补充。
