## 4. 她的方法论（可服务我们的部分）

1. **可执行订单形式化**：`e_{i,j}=min(q_{i,j}, max(0, s_i−Σ_{h<j} e_{i,h}))`——给"死单占槽"一个精确定义。
   我们所有卖单排序实验都可以用这个形式化复核（我们已实测过其结论：删空槽更优）。
2. **前缀兼容路由**：换路只能选"与当前路线前缀逐位一致"的延续 —— 防止"发明不兼容的过去"。
   我们的 day-12/648 换路是硬编码（不涉及此风险），但若未来做动态路由，这是必备护栏。
3. **终局结算律**："最后可执行回合，卖出严格优于保留（哪怕地板价）"——我们已有 final_sell_search。
4. **安全包线（Safety envelope）**：每条分支都必须"状态可验证、越界即弃权、异常回落父决策"。
   这与我们 kcheck/pack_candidate 的纪律同构，值得作为后续机制的模板。
