# 受 V50 启发的 3 个隐含方向（挖掘计划）

V50 的价值不在新架构，而在两个小而精确的层：v233x（day-11 羊毛世界条件早承诺 +
末两天停止无收益工作）和 weedlag（weed 阻塞后意图滞后重放）。同风格的隐含方向：

## 方向 1：末段"负收益工作"修剪的泛化（最贴近薄局）

V50 只对绵羊做了"day 28 起不 CARE、不喂夜里不产出的羊、day 29 不买饲料不雇闲工"。
底盘里牛（MILK）、鹅（EGG）和作物很可能还在末两天白付 CARE/FEED/饲料钱——这正是
fresh-62 薄局 ±几百块的潜在来源。做法：逐 tile 算"最后一个还能卖出的产出日"，
过了就剪掉对应工作；day 29 不雇不会干活的工。验证：fresh-62 + 375 池 + 镜像冒烟。

## 方向 2：世界条件早承诺的对称化

v233x 只做了"2/3 家 day-11 店是 YARN → 绵羊 day-11 早一天"。对称地：

- 牛奶世界（PIZZA/ICE_CREAM/SMOOTHIE 数量达标）→ 既定 COW 扩张早一天；
- 蛋世界（BAKERY/BRUNCH）→ 既定 GOOSE 扩张早一天；
- 胡萝卜世界（PET_CAFE）→ 既定 CARROT 种植/收获相位提前。

注意：不是换路线（carrot/tomato 换路线已判负），而是"tape 里既定的扩张提前一天"，
与 v233x 同构。验证：按世界分层的 h2h + 池。

## 方向 3：weedlag 泛化 —— 静默失败重放

weedlag 只覆盖"weed 挡了 BUILD/PLANT"。引擎里还有很多静默 no-op：种子不足的
PLANT（整组被丢弃）、shed 满的 DROP/PLACE、钱不够的 BUY、被动物占位的操作。
做法：对比"意图动作的期望状态"与"下一回合实际状态"，检测静默失败后按有界步数
重放意图。验证：weed 世界 + 池。

优先级：1 → 2 → 3（1 直接对应线上薄局，2 是 v233x 的天然补全，3 覆盖长尾）。

## 挖掘结果（2026-09-20）

### 方向 1：末段修剪 —— 正收益，晋升新候选

实测底盘末两天每局有 13 次白费 CARE + 0~3 次白费 FEED（牛/鹅不会再产出仍被照顾）。
实现 `v50_np_prun.py`（EXP297）：day 28~29 对"下一次产出日 > day29"的动物把
FEED/CARE 置 PASS，并**对 V 系关闭**（镜像保持对称），窗口 672–711 避开 terminal
planner。验证：

- 375 池 **318W/57L 84.8%**（farm4b 84.5%，+1）
- fresh-62 **33W/29L 53.2%**（51.6%，+1）
- timed174 128 世界 48W/80L 37.5%（35.9%，+2）；racepx 37.5%（持平）
- V50 镜像 123W/5L 96.1%（与 farm4b 逐局一致，无退化）
- 教训：最初把窗口开到 719 时 fresh-62 崩到 38.7%——day-29 的修改触发 terminal
  planner 偏差放弃；限到 711 前即恢复正收益。

#### 榨干过程（v1→v4）

- v1（FEED/CARE→PASS，day28–29，V 系关闭）：375 池 84.8%、fresh-62 53.2%、
  timed174 37.5%。
- v2（+day-27 窗口 + day-28 起全剪 BUY_SEED——晚买的种子永远长不出来）：
  fresh-62 56.5%。
- **v3（+把被剪动作位转 HARVEST，收割该动物已挂账的产出）**：375 池
  **320W/55L 85.3%**（+3）、fresh-62 **35W/27L 56.5%**（+3，mean +536）、
  timed174 **54W/74L 42.2%**（+8）、racepx **30W/34L 46.9%**（+8 vs noprot 34.4%）、
  V50 镜像 96.1% 逐局一致。
- v4 两个候选加法都判负：饱和动物修剪 −28 mean（丢弃后不采）、同回合小麦买入
  削减中性；day-26 窗口扩展无增量。最终形态 = v3。
- 已评估放弃：712–718 planner 集成（只剩 ~4 CARE/局）、WATER/FERTILIZE 修剪
  （都是终局有效工作）、DIG/PLACE/COLLECT（有效）、day-29 HIRE/BUY 已为 0。

打包 `candidate_v50_np_prun.tar.gz`（main.py SHA 46a4d854…，最终 v3）。

### 方向 2：世界条件早承诺 —— 底座已开采殆尽

实测：草莓正是 day-11 大波（13 株，interval 2 → 5 收，day-12 只有 4 收），
绵羊有 v233x day-11，牛对 ±1 天不敏感（interval 2 两相位都 6 收），day-9 已有
牛奶世界 SHEEP→COW 转换。剩余只有鹅（interval 1）提前一天的 +1 蛋，收益 ~30-80
且现金约束风险大。判定：不实施，记录为已开采。

### 方向 3：静默失败重放 —— 无料

在 3 局真实语料上扫描 PLANT/PICKUP/PLACE/DROP/BUILD/WATER 的意图-结果差异：
全部 0 次静默失败（底盘钱/种子计划足够紧）；weed 已由 weedlag 覆盖。判定：不实施。
