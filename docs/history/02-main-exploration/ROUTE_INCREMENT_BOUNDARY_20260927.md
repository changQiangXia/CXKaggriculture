# 路线级增量的落点边界（2026-09-27，三套独立证据）

结论：**"只占用空闲格 + 空闲回合"在数学上不可行**——不是落点难找，是**一个都不存在**。

## 证据 1：计划众数位置扫描（41 条 route，route_positions.json 56,210 键）
| 判据 | 结果 |
|---|---|
| ≥20 空闲回合 且 计划零占用 的格子 | **0** |
| ≥8 天空闲覆盖 且 计划占用 ≤6 次 | **0** |
| ≥15 天空闲覆盖 且 计划占用 ≤20 次 | **0** |
| 空闲回合最多的格子 | (4,4)/(5,4) 等**棚边区**——那些 PASS 是"棚边等待"，只能取货/卸货 |

## 证据 2：真实对局格子普查（40 局，逐单位逐回合）
| 判据 | 结果 |
|---|---|
| 单位站立 ≥100 次 且 被作物/动物占用 ≤200 次 的格子 | **0** |
| 访问最多的格子 | (4,4) 23,686 次 / 占用 28,560；(5,4) 16,515 / 22,474 …… 全部在耕作 |
| 最"空"的被访问格子 | (5,7)/(5,8)/(5,9)：40 局仅 **37 次**访问（≈1 次/局） |

## 证据 3：逐 route 核查 3 个长期杂草格 (1,8)/(2,9)/(3,9)
**没有任何一条 route**同时满足"该格零动作 + 空闲回合 ≥10"——它们在计划里都被使用。

## 含义
* 细胞级增量（补一株/一栏/一次喂食）没有物理位置可落：**空着的格子没人去，人常去的格子全在用**。
* 因此在 P1 字面约束下，本 goal 的产物只能是**市场槽位级**改动（买卖单），
  而那属于 P5 己列的四类已证伪改动之一（市场博弈技巧）⇒ 不可用。
* 唯一能开出空间的改法是"**接管低价值产出格**"（把某格现有的 PLANT/WATER/HARVEST
  序列整体改写为新产线），这需要把 P1 的"禁止改动既有动作的语义与顺序"放宽到
  "允许每次接管 ≤2 格、且必须给出接管前后每格-日产值对比"。
