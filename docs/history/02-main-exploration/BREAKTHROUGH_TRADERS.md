# 突破口：主动贸易型对手与肥料套牢（2026-09-20）

## 发现

从 timed174/flood50 的两个最大线上败局（Yannik Schiffner -12797、Gleb
Tumanov -5483）入手，发现它们的共同身份是**主动贸易型**：

- Yannik：BUY 小麦 2372 / SELL 3172，BUY 肥料 443 / SELL 1195。
- Gleb：BUY 小麦 1605 / SELL 1826，BUY 肥料 106 / SELL 337。

池子 328 局里这类对手占 **14.3%（47 局）**，而我们的最大败局几乎全部来自
他们（-61k ~ -2.4k 区间）。这是当前已知的最大单一损失来源。

## 输法机制（Yannik 局 money 轨迹）

- 我方一路领先到 step 336（+3136）。
- day 14-16（step 336-384）肥料价格从 56 崩到 17：对手用"动物每天免费产的
  肥料 + 市场买入"共抛售 1195 单位，价格崩盘。
- 我们的 flood50 肥料地板 0.5（价格 < 50 不卖）→ 肥料被套牢到 17，随后
  差距扩大到 -10488。

结论：**贸易型对手的核心武器 = 免费肥料量产 + 大规模抛售压价 + 套牢对手**。

## 反制方向（按可行性排序）

1. **肥料更早/更狠地抛**：FERTILIZER 的抢卖地板降到 0 且提前（全程无地板），
   在对手抛售前出清，避免套牢。
2. **贸易型检测 + 反制**：检测小麦库存骤降（对手大买）或肥料价格连续下跌
   趋势 → 触发"肥料全抛 + 反向小麦贸易"。
3. **小麦贸易对抗**：对手低买高卖，我们反着做（他们买时抬价、他们卖时压价）。

先做 1（零检测、参数级），再做 2（检测级）。

## 反制实验 1 的验证（负结果）

fert_aggro（FERTILIZER 全程无地板抢卖）：

- 16 世界镜像 28W/4L（87.5%）——样本噪声
- 64 世界镜像 100W/28L（78.1%），mean +468——与 timed174 完全相同
- 313 池 262W/51L（83.7%），mean +3550——与 timed174 逐局完全相同

原因：肥料崩盘发生在 step 174 之后（aggr 段），timed174 在该段本来就已经
无地板抢卖，所以"全程无地板"没有新增行为。参数级反制到此排除。

## 更深的判断

贸易型对手的胜利是**结构性**的：他们每天倒卖小麦/肥料赚价差（贸易利润率
高于我们的生产利润率），我方领先到 day 14 后仍被贸易利润逐步反超。这不是
单点参数能反制的；真正的对等反制需要给底座加"主动贸易能力"（低买高卖），
属于生产端重工程。方向 2（检测+反向贸易）与方向 3（贸易对抗）因此也都是
重工程，作为候选保留。

结论：突破口 = 认识到"贸易型家族（14.3%）是最大败局源、且输法是结构性
贸易利润率差"，反制需要贸易能力而非参数。
