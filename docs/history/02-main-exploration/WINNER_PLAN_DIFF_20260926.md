## 4. 结论（三条，按可操作性排序）
1. **终局空转**：我们的单位在最后 14 天每局有 176 个 PASS（≈12.6/天），赢家只有 52（≈3.7/天）。
   这 124 个回合差距，与他们卖货意图（每项 +900~1900 单位）是同一件事的两面：
   **他们把回合用在"采收→交货→卖出"的循环上，我们在发呆。**
2. **作物结构**：开局 d0–3 赢家种草莓（6.6 株）与甜瓜，我们**一株草莓都不种**；
   终局他们卖 MELON 940 单位意图、我们 **0**。这不是参数，是计划里没有这条产线。
3. **化肥与浇水**：赢家在 d8–15 与 d16–29 的 FERTILIZE 是我们的 3.2× 与 2.0×
   （t=61.3 / 55.7），而我们在 d0–3 浇水反而更多（−18.5，t=−54.3）——
   再一次印证：**我们把水浇在了"没用的时段"，他们把肥施在"能翻倍的窗口"。**

⇒ 下一步模型工作（结构层，非参数）：把"草莓/甜瓜产线"和"终局变现循环"写进计划，
优先解决那 124 个空转回合——这是目前所有证据里最大、最可量化的差距。
