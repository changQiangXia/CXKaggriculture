## 2. 机制 A：T4（镜像门控提前卖）——我们已测，判负

他的提交 `MarketShock-M1-WR1K`：底座 = 冻结的 Seven-Turn Rescue，
唯一机制 = **镜像局里把计划卖单提前 1–2 回合**（`lead = 2 if 观察到对手也在抢跑 else 1`），
并用**信用账本**抵扣原卖单（防重复卖）。

我们实测（在他这条语义上）：

| 变体 | 33 场真实线上败局 | v4family 面板（470 局） |
|---|---:|---:|
| base（rmax96，SN_H=48） | 8/33（24.2%） | **89.6%** |
| SN_H=1（全局，≈lead-1） | **11/33（33%）** | 74.7% |
| SN_H=2（全局，≈lead-2） | **11/33（33%）** | 74.3% |
| 镜像门控 SN_H=1/2（sim≥0.9 才切） | 9/33 | 74.8% / 75.1% |

⇒ **两个仪器方向相反**：窄提前卖在 33 场败局上更优，但在 470 局家族面板上把胜率砍掉 ~15pp。
大面板证据优先 ⇒ **T4 不采纳**（这也与我们的镜像取证一致：镜像局要**大**窗口、SN_H 小=输掉抢先卖竞赛）。

## 3. 机制 B：商店抽签的隐藏结构（**已证明**，这是本轮最大发现）

他的证据台账（逐条标注 Proven/Measured/Modelled/Open）：

1. **PROVEN（3,136/3,136 精确一致）**：每晚结束后引擎重置确定性 RNG
   $$R_d=\operatorname{Random}\big((s\cdot 1{,}000{,}003)\oplus d\big)$$
   （`s`=隐藏的 31 位局种子，`d`=刚结束的那天），然后**对玩家 0 的每个空格调一次 `random()`、
   再对玩家 1 的每个空格调一次**；若该夜开新店，**下一个随机值**从 8 类商店里选一家。
   即：`S_d = f(s, d, E_0 + E_1)`（E=双方"最后一次动作后、杂草生成前"的空格数）。
2. **MEASURED（98/128）**：**hour 23 的一次合法 DIG**（让空格数 +1）能改变当晚的商店抽签。
3. **REJECTED**：从 episode metadata 反推种子（0/3,954 精确匹配）；自然商店/杂草历史反推种子
   （0/98 近似；3/98 在 day24）⇒ **游戏内种子推断不可行**。
4. **OPEN**：定向商店控制能否提高天梯分——**连他自己都没过留出配对测试**。

### 我们的本地复现（2026-09-28 19:00）

实现 `pkg_shopshift`：hour 23 若有单位站在 WEED 格且动作为 PASS → 改成 `DIG`（即 +1 空格）。
在 16 场线上败局上与控制组配对跑：**商店序列不同 0/16，margin 逐位相同**。

原因：**执行器不咬合**——这 16 局里 hour 23 恰好没有"工人站在杂草上"的情形，干预从未触发。
这与他的做法差别在于：他是**特意构造**了"一格占用干预"（选好时间点与格子），而我们只是顺路钩子。

## 4. 判定

* **机制 A（T4）**：实测方向矛盾、大面板完败 ⇒ 不采纳；
* **机制 B（商店 RNG 杠杆）**：机制**真实存在**（他 3,136 次精确一致 + 98/128 干预有效），
  但① 种子不可推断（他 0/3,954、0/98 的硬负结论）② 他自己标注**经济价值 OPEN**。
  ⇒ 在没有种子知识的前提下，干预只能"重掷"一次随机抽签，**期望收益≈0**；
  要变现必须先解决"给定种子预测 8 类商店"或"多次重掷直到出现目标店"——
  前者被证否、后者需要多个可控空格（我们的棚/田地容量与工时不允许）。
* **方法论收获**：① "冰与火"分解（不变核 vs 状态响应叉）——与我们"固定骨架 + 状态门控"同构；
  ② 他的证据分级（Proven/Measured/Modelled/Open）值得作为我们的落档模板；
  ③ 商店抽签公式确认了我们 147 局分析中"店铺抽签是外生变量"的判断。
