# 结构性重写 goal 进展（13–14 手 + 4 象限经济）

## 0. 目标与门径

以真实 13–14 手 + 4 象限计划为蓝本，整体重写手序/雇工曲线/买卖窗口。
门径：G2 = 2400+ 池配对 Δ ≥ +100 且 t ≥ 2（vs ch99）；G3 = 低段池 Δ ≥ −20；零提交。

## 1. 底座盘点：蓝图已经部分存在

ch99 不是"3 象限磁带"，它自带多条投资/规划层（f2b 构建）：

| 层 | 触发 | 动作 |
|---|---|---|
| **V219** | d18 一步判定：恰好 {NW,NE,SW} 三象限 + 现金 ≥12k + TOMATO 价 ≥70 + PIZZA_SHOP/FARMERS_MARKET 计数 ≥3 + SE 未动 + 原生磁带无买地/番茄 | 买地 4k + 10 番茄种 + 2–3 名专职手，d26–29 收获/交货/卖番茄；d24/27 施肥 |
| **V233** | d11–12：YARN_STORE ≥2 + WOOL ≥220 + WHEAT ≤45 | 买地 + 6 只绵羊进 SE，喂/护理/收毛 |
| **AX 规划器** | 每步 | 买地/雇工/卖出模拟（`_ax_frontload`、`_ax_advance_sales`） |

## 3. V219 的触发经济学（150 局解剖）

* 触发 27/150；触发时收益 **+10,362/局**（中位 +8,261，最高 +37,716）。
* 与 d18 番茄价的关系：70–75 → −177（2 局）；75–80 → +5,935（13 局）；80–90 → +14,295（10 局）；90+ → +30,002（2 局）；shops ≥4 → +23,218（5 局）。
* 触发率 18%：11/16 的局被"shops_pf<3"拒绝，4/16 被"番茄价<70"拒绝。

## 4. 语料交叉验证

* 低番茄需求的局（pf≤2）里抽查 8 位 2700+ 选手：6 局 quads=3、SE 全空（他们也不投）；2 局分别用了 TOMATO×10 / SHEEP×6。
  ⇒ 112 局"SE 闲置"不是漏掉的收益，而是需求不足时的正确选择。
* 结构对齐：我们的 4 象限局与 2775–2843 蓝图的 d24 地格完全同构（64c/17a、同样的 3 个杂草格与 SE 布局）。
* 终局无滞留：shed TOMATO / 随身 TOMATO 在 d29 之后均为 0（没有烂在手里的货）。
