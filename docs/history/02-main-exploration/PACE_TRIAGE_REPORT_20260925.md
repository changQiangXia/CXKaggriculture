## 4. 结论与教训

1. **该层丢弃**：`triage_v1` 不进任何候选，`candidate_final` 未改动。
2. **选择偏置是真实的**：在 n=114、SE=6.9 的弱桶上挑出 +15（t=2.19）很容易；把样本放大到 2,567 局
   （SE=1.2）后真效应是 −2.7。**任何在 100–200 局面板上 t≈2 的"新机制"都应按此标准复核。**
3. **方法资产**：`counter_panel.py --extra-seeds N`（每条真实对手 tape × N 个新种子）把冻结语料的
   统计功效提高了 ~20 倍（SE 5.4 → 1.2），成本只有几分钟；这是以后所有"时机/微扰"类假设的判决工具。
4. **机制层面的读数**：节奏键（现金差/对手产能）**能分诊强弱，但不能指出可改动点**——
   ER 层只是"跟着对手抛售窗口出手"的变现层，在弱局里提前 2 天开始并没有可测量的价值。
