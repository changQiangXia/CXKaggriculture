## 打包与 loader 校验（本次新增，重要）

- **抓到一个会让提交白费的 bug**：Kaggle 的 loader 取"模块中最后一个 callable"，
  而 `agent = 某函数` 属于**重绑定已存在的键**，不会把它移到字典末尾——所以朴素追加
  的包装层会被 loader 忽略，实际跑的是底座本体。
  本次已在三层（daybreak / cash_guard / cash_guard_plus）末尾补上
  `agent = globals().pop('agent')` 封印。
- 校验（从 tar 解出 main.py 后）：
  `loader entrypoint: agent（telemetry=True）`，冒烟对局 719 步正常结束。
