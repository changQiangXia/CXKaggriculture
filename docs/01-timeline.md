## 阶段一 · 早期搜索（09-12 ~ 09-18）

**从哪里开始：** 一个可跑的公开 notebook + 一套自己搭的验证工具。

**这阶段做对的最重要一件事：第一天就审计引擎。**

线上回放报告的模块版本是 `1.32.7`，本地装的是 `1.25.9`。我们没有直接相信
"版本不同但应该差不多"，而是把 4 局线上对局的动作逐条重新喂进本地引擎，
**逐状态比对**：

| 回放 | 步数 | 首次分歧 |
|---|---|---|
| 108204611 | 720 | **无** |
| 108205627 | 720 | **无** |
| 108206966 | 720 | **无** |
| 108208668 | 720 | **无** |

最终奖励完全相同。这为后续本地实验提供了可信起点；它证明本地引擎能逐状态
复现这 4 局，不证明所有隐藏状态或规则分支都已覆盖。

**这阶段归档的五次提交均失败或远低于当时目标：**

| ref | 结果 |
|---|---|
| 56170379 | complete，约 1100–1165 |
| 56170496 | **ERROR**（tar 打包问题） |
| 56170591 | complete，约 997–1598，不稳定 |
| 56170774 | **ERROR**（期望外部 actions.json —— Kaggle 只加载 main.py） |
| 56171485 | complete，约 847 起爬 |

当时第 200 名约 **2697 分**，我们差得很远。

**这阶段的关键认知：镜像问题。**
最强的公开 bot 被抄得最多，于是**你最大的对手就是你自己**。
farm2945 自我对局：36 个世界 → **3 胜 3 负 66 平**。
平局对高分账号是扣分的，所以"照搬最强的公开 bot"是自毁。

→ 由此产生了第一个结构性想法：**两阶段定时切换**
（前 200 步保守、之后激进），不需要检测器就能同时打镜像和激进克隆。

## 阶段二 · 主探索（09-19 ~ 09-29）

**架构在这一阶段定型：41 条完整路线 + 约 60 个包装/控制点。**

每条路线包含 719 个可执行 step（0–718），按公开商店状态选择世界专属路线，
再在外面套手写层，在特定条件下改写具体决策。
为什么用磁带而不是学习策略？因为学习策略试过、失败了（见阶段三）。

第 6 天根据前两个解锁商店选路线；第 12–19 天固定路线 104，第 20–26 天
固定路线 120，第 27 天起切到路线 2。`w2_120` 正是“第二个中后段窗口用
路线 120”的缩写。完整 Router 与层栈见 [`06-our-agent.md`](06-our-agent.md)。

**这一阶段大量工作是"测绘"而不是"优化"：**

- 逐个分数段统计胜率（band-by-band），知道自己在哪一段输；
- 统计败局对手的终局经济画像；
- 针对特定对手族群做反制（反牛奶、反羊毛、牛优先、羊优先……）；
- 反复得到一个结论：**反制针对的目标有效，但付的代价更大。**

**这一阶段最重要的发现是「保真度问题」：**

面板对手是录下来的磁带。如果你的 agent 饿死了它——抢走它需要的麦子、
淹没它的卖单——它会继续按录像走一个**已经不存在的游戏**。
你会"赢"一局对手从未真正参与的比赛。

→ 对策：**保真度过滤**（只统计对手最终资金 ≥ 记录值 95% 的对局），
并且**只信配对差值、不信绝对胜率**。

**这一阶段结束时，出现了第一次"离线好、线上差"的悖论：**

> 8 个 `mid112` 候选，570 局冻结语料上 **+457 margin（t = 9.22）**，
> 但线上分数卡在约 2090，名次从 #322 滑到 #1105。

我们当时把它当作异常。**它其实是整场比赛最重要的信号**，
在最后一天以另一种形式再次出现（见 [`04-lessons.md`](04-lessons.md)）。

## 阶段三 · 冲刺与复盘（09-30 ~ 10-02）

**最后 38 小时。** 逐小时日志见 [`experiment-log.md`](experiment-log.md)。

### 3.1 先把手头的方向榨干

60/60 个包装点消融、拼接 27 组合、市场流约 350 个变体、动物替代、
劳动重定时、RL 沙盒、算子移植……几乎全负。

**两项结构性观察：**

- 逐小时诊断显示，多个高峰时段的劳动日程接近满负荷；利用率数值随统计口径
  变化，不能概括为全程固定的 95%。每只牲畜每天仍需约 2.2 个动作。
  “救羊”实验支持机会成本解释：救回 154 只羊时，用掉约 35k 劳动价值换
  77k 资本，净亏；这不能证明逃逸在所有世界都是全局最优。
- 在该阶段测试的结构性算子均为负或中性，存活改动主要来自参数与开关；
  这不排除换用学习策略或计划级架构。

### 3.2 终局常量扫描中最强的真信号

扫了约 60 个常量与阈值家族：

- 约 12 个在当时的 108 局扫描中是**死代码**（未改变动作轨迹）；
- 若干**已经站在悬崖正确一侧**；
- **只有一个是真正卡在错误一侧的开关：**

```
V9_FERT_FIRST_DAY   14 -> 12      +84 margin/局
```

三池验证 +84（t=5.10）、+82（t=4.67）、+94（t=2.47）。
阈值扫描在该面板上呈**窗口开关**行为：12 与 13 逐局完全相同，14 恰好错过窗口。

**而它早就被测过、并被扔掉了**——因为那次用的是**胜负判据**
（"−1 胜，惰性"）。换成配对边际后立刻变成 t=4.67。

### 3.3 修尺子

两件事让差异变得可测：

**配对**——相同对手、相同世界、相同种子：

| | 标准差 |
|---|---|
| 单局金额差 | **13,129** |
| 配对差 | **201**（紧 65 倍） |

**用边际而不是胜负**——胜负把连续效应压成 0/1，
在"没有一局靠近临界线"的样本里，一个真实的 +84/局改进可以翻**零**局。

### 3.4 提交

三行改动（`V9_FERT_FIRST_DAY 14→12`、`_R37_PRICE_FLOOR 1→2`、
`_R37_HINGE_GAIN 8→6`），三池效应 **+112 / +108 / +113**。

**09-30 20:32 提交 `comb2b`**，首个 public 观测为 2109.3；同日较早的父本
`comb` 为 1943.9。两次读数并非同一时间窗的配对实验，165 分是支持性而非因果证据。
