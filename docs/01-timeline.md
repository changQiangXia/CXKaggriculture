## 阶段二 · 主探索（09-19 ~ 09-29）

**架构在这一阶段定型：磁带 + 约 60 层策略层。**

720 个录好的回合逐字重放，外面套手写层，在特定条件下改写具体决策。
为什么用磁带而不是学习策略？因为学习策略试过、失败了（见阶段三）。

**这一阶段大量工作是"测绘"而不是"优化"：**

- 逐个分数段统计胜率（band-by-band），知道自己在哪一段输；
- 统计败局对手的终局经济画像；
- 针对特定对手族群做反制（反牛奶、反羊毛、牛优先、羊优先……）；
- 反复得到一个结论：**反制针对的目标有效，但付的代价更大。**

**这一阶段最重要的发现是「保真度问题」：**

面板对手是录下来的磁带。如果你的 agent 饿死了它——抢走它需要的麦子、
淹没它的卖单——它会继续按录像走一个**已经不存在的游戏**。
你会"赢"一局对手从未真正参与的比赛。

→ 对策：**保真度过滤**（只统计对手最终资金 ≥ 记录值 95% 的对局），
并且**只信配对差值、不信绝对胜率**。

**这一阶段结束时，出现了第一次"离线好、线上差"的悖论：**

> 8 个 `mid112` 候选，570 局冻结语料上 **+457 margin（t = 9.22）**，
> 但线上分数卡在约 2090，名次从 #322 滑到 #1105。

我们当时把它当作异常。**它其实是整场比赛最重要的信号**，
在最后一天以另一种形式再次出现（见 [`04-lessons.md`](04-lessons.md)）。

## 阶段三 · 冲刺与复盘（09-30 ~ 10-02）

**最后 38 小时。** 逐小时日志见 [`experiment-log.md`](experiment-log.md)。

### 3.1 先把手头的方向榨干

层消融 60 层全扫、拼接 27 组合、市场流约 350 个变体、动物替代、
劳动重定时、RL 沙盒、算子移植……几乎全负。

**两条结构性结论：**

- 磁带在 **约 95% 劳动利用率**下运行，每只牲畜每天要 **约 2.2 个动作**。
  所以"让一部分牲畜逃逸"不是 bug，而是固定劳动预算下的**最优剪裁**。
  我们实测：救回 154 只羊，用掉 35k 劳动价值换 77k 资本，**净亏**。
- **加行为永远亏；只有改参数能赚。**

### 3.2 唯一的真发现

扫了约 60 个常量与阈值家族：

- 约 12 个是**死代码**（改动后逐字节相同）；
- 若干**已经站在悬崖正确一侧**；
- **只有一个是真正卡在错误一侧的开关：**

```
V9_FERT_FIRST_DAY   14 -> 12      +84 margin/局
```

三池验证 +84（t=5.10）、+82（t=4.67）、+94（t=2.47）。
阈值扫描显示它是**开关**：12 与 13 逐局完全相同，14 恰好错过窗口。

**而它早就被测过、并被扔掉了**——因为那次用的是**胜负判据**
（"−1 胜，惰性"）。换成配对边际后立刻变成 t=4.67。

### 3.3 修尺子

两件事让差异变得可测：

**配对**——相同对手、相同世界、相同种子：

| | 标准差 |
|---|---|
| 单局金额差 | **13,129** |
| 配对差 | **201**（紧 65 倍） |

**用边际而不是胜负**——胜负把连续效应压成 0/1，
在"没有一局靠近临界线"的样本里，一个真实的 +84/局改进可以翻**零**局。

### 3.4 提交

三行改动（`V9_FERT_FIRST_DAY 14→12`、`_R37_PRICE_FLOOR 1→2`、
`_R37_HINGE_GAIN 8→6`），三池效应 **+112 / +108 / +113**。

**09-30 20:32 提交 `comb2b`**，开分 2109.3，比父本高 165。
