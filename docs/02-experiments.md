# 02 · 实验总账

按"试过什么 → 结论"整理。这一页的目的是让下一次不必重走这些路。

## A. 架构与策略

| 实验 | 规模 | 结论 |
|---|---|---|
| 层消融（60 层全扫） | 108 局/变体 | 只有 `V92_P`、`V9_RACE` 是真税；其余层承重，拆即崩 |
| 拼接（路线 × 窗口 × 边界） | 27 组合 | 现役 `d12-19=104 / d20-26=120` 即联合最优 |
| 跨局捐赠者移植 | 96 局 | 5–11 胜——状态绑死，不可迁移 |
| 固定开局替换 | 12 变体 × 108 | 全部 63W（基线 64W） |
| 两阶段定时切换 | 多世界 | 能同时打镜像与激进克隆，但绝对强度不足 |

## B. 市场

| 实验 | 规模 | 结论 |
|---|---|---|
| 市场流合成 | 约 350 候选 | 全部为负或惰性 |
| 逐点搜索（303 点） | — | 无收益 |
| `sells_first` | — | 自博弈伪影（0–64） |
| 日内高点卖 / 低点买 | — | −9k / −10 胜 |
| 卖单拆分 | — | −38 胜（现金流断裂） |
| 囤货 | — | 惰性 |
| 订单重排算子（v44y/s793） | 实盘 108 局 | 模型内 +47~+101，**实盘 0 变化** |

**根因**：算子模型的对手假设是**镜像**（用基线订单当对手）。
模型内收益 ±50–100，而实盘噪声 ±10k——差两个数量级。

## C. 非现金流机制

| 实验 | 结论 |
|---|---|
| **棚屋溢出** | 机制确实会销毁（超 100 直接 `del`），但实测仅 **338 件 / 16,676 金 / 108 局 ≈ 154 金/局**，属噪声 |
| **动物逃逸** | 真实且大额（372 只 / 176,200 金 / 108 局），但**救不回来**：3 个补喂算子全部净负 |
| **田块产出上限浪费** | **不存在**——初版探针误把"触及上限"当成"浪费"，重建后销毁数 = 0 |
| **终局携带清货** | 更差（两局分别多输 10k / 6.6k） |

## F. 评估方法本身

| 实验 | 结论 |
|---|---|
| 配对评估 | 噪声从 sd 13,129 压到 **201**（65 倍） |
| 保真度过滤（fid ≥ 0.95） | 剔除"冻结对手被饿死"的对局 |
| Bradley–Terry 拟合 | 分池拟合可收敛；**跨池合并会因稀疏无界而退化** |
| 直接对打（256 局，双向座位） | 与冻结回放结论**相反**——未解决 |
