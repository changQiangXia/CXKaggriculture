# 02 · 实验总账

按"试过什么 → 结论"整理。这一页的目的是让下一次不必重走这些路。

需要先看方案结构时，请读 [`06-our-agent.md`](06-our-agent.md)。本文保留
实验账本，重点记录每个方向为什么被保留或被否定。

## A. 架构与策略

| 实验 | 规模 | 结论 |
|---|---|---|
| 层消融（60 层全扫） | 108 局/变体 | 只有 `V92_P`、`V9_RACE` 是真税；其余层承重，拆即崩 |
| 拼接（路线 × 窗口 × 边界） | 27 组合 | 现役 `d12-19=104 / d20-26=120` 即联合最优 |
| 跨局捐赠者移植 | 96 局 | 5–11 胜——状态绑死，不可迁移 |
| 固定开局替换 | 12 变体 × 108 | 全部 63W（基线 64W） |
| 两阶段定时切换 | 多世界 | 能同时打镜像与激进克隆，但绝对强度不足 |

## B. 市场

| 实验 | 规模 | 结论 |
|---|---|---|
| 市场流合成 | 约 350 候选 | 全部为负或惰性 |
| 逐点搜索（303 点） | — | 无收益 |
| `sells_first` | — | 自博弈伪影（0–64） |
| 日内高点卖 / 低点买 | — | −9k / −10 胜 |
| 卖单拆分 | — | −38 胜（现金流断裂） |
| 囤货 | — | 惰性 |
| 订单重排算子（v44y/s793） | 实盘 108 局 | 模型内 +47~+101，**实盘 0 变化** |

**根因**：算子模型的对手假设是**镜像**（用基线订单当对手）。
模型内收益 ±50–100，而实盘噪声 ±10k——差两个数量级。

## C. 非现金流机制

| 实验 | 结论 |
|---|---|
| **棚屋溢出** | 机制确实会销毁（超 100 直接 `del`），但实测仅 **338 件 / 16,676 金 / 108 局 ≈ 154 金/局**，属噪声 |

| **终局携带清货** | 更差（两局分别多输 10k / 6.6k） |

## F. 评估方法本身

| 实验 | 结论 |
|---|---|
| 配对评估 | 噪声从 sd 13,129 压到 **201**（65 倍） |
| 保真度过滤（fid ≥ 0.95） | 剔除"冻结对手被饿死"的对局 |
| Bradley–Terry 拟合 | 分池拟合可收敛；**跨池合并会因稀疏无界而退化** |
| 直接对打（256 局，双向座位） | 与冻结回放结论**相反**——未解决 |

## G. 最后一天：搜索树怎样收敛

最后一天不是“随机多试几个包”，而是按造价从低到高逐层排除：

| 搜索层级 | 代表实验 | 观测到的边界 |
|---|---|---|
| 路线层 | 9 个 104/112/120 双窗口组合；13 个 day-6 单路线 | 最好 3/44 败局；现役路由表更有效 |
| 表拟合 | day-6 表 52 格 LOO；对手例外表 LOO | 样本内 oracle 变好，留出集反而变差，判为过拟合 |
| 边界层 | 432/456/480/528 与 27 组联合边界 | 480 保留；现役 104/120 为联合最优 |
| 捐赠者移植 | d14+ 整段、物理片段、市场片段 | 同局 oracle 可翻 22/40，跨局只有 5–11/96，状态绑死 |
| 行为层 | 番茄拓宽/提前、羊替换、补喂、终局清货 | 局部有机制，但破坏劳动或现金流后净负 |
| 市场层 | 囤麦、回卖、化肥、逐品混流、卖单拆分、买卖重定时 | 多数负；断现金流或成为冻结面板伪影 |
| 订单算子 | v44y/s793、新写买侧/卖侧三个算子 | 模型内 +47~+101，实盘无变化或负；对手模型假设错误 |
| 层消融 | 先测 32 个，再补齐遗漏的 25 个，合计 60/60 | `V92_P`/`V9_RACE` 已知为税；无隐藏正层 |
| 常量/阈值 | 约 60 个，含悬崖双向探针 | 只新增一个未取用开关：`V9_FERT_FIRST_DAY 14→12` |

这张表解释了两点：

1. “没有新 tape”不是没有尝试，而是拼接、移植、混流和补丁四个廉价形态
   都被系统测过；
2. “只改 6 行”不是偷懒，而是在大量结构实验失败后，经过配对检验找到的
   最小可交付改动。

## H. 证据强度分级

读历史笔记时，建议按下面的顺序相信证据：

1. **线上最终 BT 分**：真正决定名次，但受时段、对手和爬分基线影响；
2. **固定真实对局的多候选配对**：同对手、同 seed，适合判断小幅 margin，
   但不能模拟活对手；
3. **直接对打**：能观察反应，但两边 agent 都为打别人设计，仍有盲区；
4. **冻结面板绝对胜率**：最容易因对手被饿死而失真，只能用于筛选；
5. **单局/小样本**：只用于定位机制，不用于宣称候选更强。

两个必须保留的结论：

* 胜场计数会漏掉连续 margin 信号。`V9_FERT_FIRST_DAY` 在胜场口径下是
  “−1 胜”，在 131 局配对口径下是 `+82/局，t=4.67`；
* 冻结回放与直接对打可以得出相反排序。我们记录这个矛盾，不按最终线上
  结果反向改写实验事实。
